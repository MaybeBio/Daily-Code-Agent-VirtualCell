Model assumptions and sources

The patch uses seeded synthetic positions and nearest-neighbor contacts within retinal layers. Each cell integrates signed inputs in 10 ms steps. Cones reduce release under light, ON bipolar cells invert that change, and OFF bipolar cells preserve its sign and adapt to sustained input. Ganglion rates are illustrative. Cell brightness shows the magnitude of change from baseline.

The synj1 presets weaken and slow cone output. The contact-loss option also removes a seeded fraction of modeled invaginating contacts. The sliders set model parameters. Gain values are dimensionless, and the matrix averages their absolute values over all baseline contacts in each pathway, counting removed contacts as zero.
