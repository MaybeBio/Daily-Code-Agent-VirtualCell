### LLM Integration and Configuration
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) project integrates various Large Language Models (LLMs) through a centralized system that supports multiple providers and offers flexible configuration options. This integration is primarily managed by the [`get_llm`](https://github.com/snap-stanford/biomni/biomni/llm.py#L13) factory function, located in [`/snap-stanford/biomni/biomni/llm.py`](https://github.com/snap-stanford/biomni/biomni/llm.py), which instantiates chat models from providers such as OpenAI, Anthropic, Ollama, Gemini, and Bedrock.

Configuration for these LLMs can be managed through a hierarchy of settings, including environment variables, a [`default_config`](https://github.com/snap-stanford/biomni/biomni/config.py#L99) object, and direct parameters during agent instantiation. The [`BiomniConfig`](https://github.com/snap-stanford/biomni/biomni/config.py#L13) dataclass in [`/snap-stanford/biomni/biomni/config.py`](https://github.com/snap-stanford/biomni/biomni/config.py) centralizes these settings, allowing overrides from environment variables for flexible deployment. The [`get_llm`](https://github.com/snap-stanford/biomni/biomni/llm.py#L13) function automatically detects the LLM provider based on model names or environment variables and dynamically imports the necessary LangChain chat model classes. It also incorporates provider-specific logic, such as handling API quirks for newer OpenAI models or sourcing API keys from specific environment variables for Anthropic and Gemini. This modular approach ensures that the system can adapt to different LLM services and configurations while maintaining a consistent interface for the agents. For more details on overall project structure, refer to [Project Overview and Core Components](#project-overview-and-core-components).
