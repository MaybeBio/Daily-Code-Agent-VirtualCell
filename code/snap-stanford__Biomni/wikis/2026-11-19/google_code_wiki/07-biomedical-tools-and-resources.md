## Biomedical Tools and Resources
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework provides a wide array of tools and resources for biological and medical analyses. These resources are dynamically managed and retrieved to support autonomous research tasks. A core component of this system is the intelligent selection of relevant tools and information, driven by Large Language Models (LLMs). This allows the system to effectively respond to user queries by identifying and utilizing the most appropriate resources from its extensive collection.

The system incorporates a comprehensive suite of biomedical tools, organized by scientific discipline within the [`/snap-stanford/biomni/biomni/tool`](https://github.com/snap-stanford/biomni/biomni/tool) directory. These tools cover areas such as biochemistry, bioengineering, bioimaging, cancer biology, cell biology, genomics, immunology, molecular biology, and microbiology. Each tool is designed to perform specific analytical tasks, ranging from protein sequence analysis and enzyme kinetics to advanced image processing and genomic sequencing interpretation. For example, tools in biochemistry can analyze circular dichroism spectra, while bioimaging tools leverage [`nnUNet`](https://github.com/snap-stanford/biomni/biomni/tool/bioimaging.py#L32) for segmentation and [`SimpleITK`](https://github.com/snap-stanford/biomni/biomni/tool/bioimaging.py#L11) for image registration. [Comprehensive Biomedical Tool Suite](#biomedical-tools-and-resources-comprehensive-biomedical-tool-suite) provides a more detailed overview of these specialized tools.

Beyond analytical tools, [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) also manages a rich collection of structured know-how documents and protocols. These include detailed guides, such as those for sgRNA design in CRISPR experiments and best practices for single-cell RNA-seq cell type annotation, which are stored as Markdown files within the [`/snap-stanford/biomni/biomni/know_how`](https://github.com/snap-stanford/biomni/biomni/know_how) directory. This structured knowledge is crucial for guiding the AI agent in complex experimental design and data interpretation tasks. [Know-How Documents and Protocols](#biomedical-tools-and-resources-know-how-documents-and-protocols) offers further details on these documents.

The dynamic retrieval of these resources is handled by the [`ToolRetriever`](https://github.com/snap-stanford/biomni/biomni/model/retriever.py#L8) class, primarily found in [`/snap-stanford/biomni/biomni/model/retriever.py`](https://github.com/snap-stanford/biomni/biomni/model/retriever.py). This class uses LLM prompt-based selection to interpret user queries and determine which tools, data lake items, software libraries, or know-how documents are most relevant. The LLM is given detailed descriptions of available resources and explicit instructions to select those pertinent to the query, effectively translating natural language requests into actionable resource selections. This enables the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) agent to maintain context and adapt its capabilities based on the specific biomedical problem at hand. [Dynamic Resource Management and Retrieval](#project-overview-and-core-components-dynamic-resource-management-and-retrieval) further explains this process.

Additionally, the framework integrates specialized tools for laboratory automation and literature research. This includes tools for interacting with laboratory robotics platforms like PyLabRobot, enabling dynamic access to documentation and script testing. For academic research, the system offers tools to search and extract content from databases such as PubMed and arXiv, and to perform advanced web searches, enhancing the agent's ability to gather information from scientific literature. [Lab Automation and Literature Tools](#biomedical-tools-and-resources-lab-automation-and-literature-tools) describes these functionalities in more detail.
