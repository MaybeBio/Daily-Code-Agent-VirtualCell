### LLM-based Task Extraction from BioRxiv Papers
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework includes functionality to automatically extract structured information from bioRxiv pre-print papers, converting scientific text into actionable data such as tasks, databases, and software mentioned within the research. This process is driven by Large Language Models (LLMs) and is designed to streamline the discovery of research methodologies and resources.

The core workflow for extracting information from bioRxiv papers is orchestrated by the [`extract_biorxiv_tasks.py`](https://github.com/snap-stanford/biomni/DETAILS.md#L84) script, located at [`/snap-stanford/biomni/biomni/biorxiv_scripts/extract_biorxiv_tasks.py`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/extract_biorxiv_tasks.py). This script begins by parsing command-line arguments that define parameters such as the subject area of interest, the number of papers to process, the specific LLM to use, and output directories. It then loads bioRxiv metadata from a CSV file, filtering papers based on specified subjects and publication status.

For each selected paper, the system downloads its PDF using [`download_pdf`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/extract_biorxiv_tasks.py#L122) and extracts the textual content from it via [`extract_text_from_pdf`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/extract_biorxiv_tasks.py#L159). To manage the input size for the LLM, the extracted text is truncated by [`truncate_text`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/extract_biorxiv_tasks.py#L181) while attempting to preserve sentence integrity. The crucial step of information extraction is performed by an external [`PaperTaskExtractor`](https://github.com/snap-stanford/biomni/biomni/agent/env_collection.py#L12) agent, which processes the paper's text to identify and categorize tasks, databases, and software. The results for each paper are saved as individual JSON files. Finally, [`generate_summary`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/extract_biorxiv_tasks.py#L292) aggregates these individual extractions into comprehensive summaries, including CSV files for each category and a JSON file detailing the frequency of each unique entity. The design of this script emphasizes modularity, external LLM agent utilization, idempotency for resuming interrupted processes, and extensive command-line configurability.

To manage the analysis across multiple bioRxiv subjects, the [`process_all_subjects.py`](https://github.com/snap-stanford/biomni/DETAILS.md#L86) script at [`/snap-stanford/biomni/biomni/biorxiv_scripts/process_all_subjects.py`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/process_all_subjects.py) acts as an orchestrator. It parses arguments to configure parameters such as the number of papers per subject, output paths, and LLM model. This script verifies the availability of papers for specified subjects and then iteratively calls [`extract_biorxiv_tasks.py`](https://github.com/snap-stanford/biomni/DETAILS.md#L84) for each subject. After individual subject processing is complete, [`combine_summaries`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/process_all_subjects.py#L199) aggregates the frequency summaries generated for each subject into a global [`combined_summary.json`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/process_all_subjects.py#L261) and separate CSV files, providing a consolidated view of tasks, databases, and software across all analyzed subjects.

Further leveraging the insights gained from task extraction, the [`generate_function.py`](https://github.com/snap-stanford/biomni/DETAILS.md#L85) script at [`/snap-stanford/biomni/biomni/biorxiv_scripts/generate_function.py`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts/generate_function.py) facilitates the automatic generation of Python functions from JSON-defined task descriptions. This script takes a JSON file containing task descriptions, uses an LLM-powered [`FunctionGenerator`](https://github.com/snap-stanford/biomni/biomni/agent/function_generator.py#L22) agent to convert these descriptions into executable Python code, and saves the generated code to a specified output directory. This capability allows the system to not only identify research tasks but also to automatically create computational tools to address them.
