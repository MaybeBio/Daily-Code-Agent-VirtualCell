### BiomniEval1 Benchmark Evaluation Utilities
The [`BiomniEval1`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py#L14) class provides a unified interface for evaluating responses to various tasks within the BiomniEval1 benchmark. Its primary role is to load a dataset of benchmark tasks and their ground truth, and then to compute a score for a given user answer. This class, defined in [`/snap-stanford/biomni/biomni/eval/biomni_eval1.py`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py), is made accessible via [`/snap-stanford/biomni/biomni/eval/__init__.py`](https://github.com/snap-stanford/biomni/biomni/eval/__init__.py).

At its core, [`BiomniEval1`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py#L14) loads the benchmark dataset, which contains information about different tasks, including prompts, ground truth answers, and unique identifiers. It optimizes lookup of individual task instances, allowing for quick retrieval of specific problems and their corresponding correct answers.

The evaluation process is handled by methods that compare a user's generated answer against the established ground truth. This comparison is not one-size-fits-all; instead, [`BiomniEval1`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py#L14) employs task-specific logic to calculate rewards. For some tasks, evaluation might involve simple string comparisons, while others, particularly those requiring structured outputs, might necessitate parsing JSON objects or evaluating complex data structures to identify correctness. This flexible approach accommodates the diverse range of problems presented in the biomedical domain, from factual recall to complex diagnostic reasoning.

Beyond evaluating individual answers, the [`BiomniEval1`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py#L14) class also offers utilities for retrieving task-related information. Users can list all available tasks, query statistics about the dataset (such as the number of instances per task or split), and retrieve specific instances or subsets of instances for a given task. This facilitates not only the evaluation of AI agents but also the exploration and understanding of the benchmark itself. For a broader view of task management within the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework, refer to [Foundational Task Interface and Implementations](#task-management-and-evaluation-foundational-task-interface-and-implementations).
