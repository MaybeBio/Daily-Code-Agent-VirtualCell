### Incremental Software Updates and Version Management
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework facilitates incremental updates and installations of software packages and libraries to manage its evolving dependencies. This process is primarily handled by shell scripts designed to add new software components to an existing environment without requiring a full reinstallation.

For instance, the [`/snap-stanford/biomni/biomni_env/new_software_v008.sh`](https://github.com/snap-stanford/biomni/biomni_env/new_software_v008.sh) script automates the installation of dependencies specific to Biomni version 0.0.8. This script uses a combination of package managers:
*   [`pip`](https://github.com/snap-stanford/biomni/README.md#L46) is extensively used for Python packages such as [`transformers`](https://github.com/snap-stanford/biomni/biomni_env/fixed_env.yml#L705), [`sentencepiece`](https://github.com/snap-stanford/biomni/biomni_env/fixed_env.yml#L647), [`langchain-google-genai`](https://github.com/snap-stanford/biomni/biomni_env/README.md#L72), [`langchain_ollama`](https://github.com/snap-stanford/biomni/biomni/llm.py#L229), and [`mcp`](https://github.com/snap-stanford/biomni/biomni/tool/example_mcp_tools/pubmed_mcp.py#L8). It also supports direct installations from Git repositories, as seen with [`popV`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L46) and [`pylabrobot`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L220).
*   [`uv`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L2211), a faster Python package installer, is employed for certain packages like [`transcriptformer`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L2443) and [`arc-state`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L2211), indicating an adoption of more efficient dependency management tools.
*   [`conda`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L30) is utilized for packages that might have complex dependencies or are better managed within the Conda ecosystem, such as [`weasyprint`](https://github.com/snap-stanford/biomni/README.md#L234).
*   System-level installations, like [`git-lfs`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L2211), are managed to handle large files often associated with scientific datasets and models.

This approach allows for flexible and targeted updates, ensuring that the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) environment remains current with its software requirements while minimizing the overhead of full environment rebuilds. For a comprehensive overview of environment setup, refer to [Environment Setup and Management](#environment-setup-and-management).
