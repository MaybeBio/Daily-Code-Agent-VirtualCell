### Dynamic Resource Management and Retrieval
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) agent dynamically manages and retrieves various resources, including tools, data lake items, software libraries, and know-how documents. This dynamic handling allows the agent to adapt its capabilities to the specific task at hand, leveraging external knowledge and computational power as needed. The core mechanism for this is the [`ToolRetriever`](https://github.com/snap-stanford/biomni/biomni/model/retriever.py#L8), which uses a Large Language Model (LLM) to select the most relevant resources based on a user's query, thereby informing the agent's context.

The process begins when an agent receives a query or prompt. Rather than having a fixed set of capabilities, the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) agent can intelligently scan a vast collection of available resources. These resources are comprehensively described in metadata repositories, such as [`data_lake_dict`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L2) and [`library_content_dict`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L82) found in [`/snap-stanford/biomni/biomni/env_desc.py`](https://github.com/snap-stanford/biomni/biomni/env_desc.py), which detail biomedical datasets and computational tools, respectively. For commercial applications, a curated version, [`/snap-stanford/biomni/biomni/env_desc_cm.py`](https://github.com/snap-stanford/biomni/biomni/env_desc_cm.py), filters resources based on licensing. Structured know-how documents, like those detailing sgRNA design or single-cell RNA-seq annotation in [`/snap-stanford/biomni/biomni/know_how`](https://github.com/snap-stanford/biomni/biomni/know_how), also form a crucial part of this resource pool.

The [`ToolRetriever`](https://github.com/snap-stanford/biomni/biomni/model/retriever.py#L8) in [`/snap-stanford/biomni/biomni/model/retriever.py`](https://github.com/snap-stanford/biomni/biomni/model/retriever.py) plays a central role. It takes the user's query and the descriptions of all available resources, then formulates a detailed prompt for an LLM. This prompt guides the LLM to understand the user's intent and identify which tools, datasets, software libraries, or know-how documents are most pertinent. The LLM's response, typically a list of indices corresponding to the selected resources, is then parsed by the retriever. This allows the agent to efficiently narrow down its operational scope and equip itself with only the necessary components, enhancing both relevance and computational efficiency. The retrieved resources subsequently update the agent's system prompt, ensuring the LLM's reasoning is grounded in the most relevant context and available capabilities. This mechanism allows the agent to dynamically integrate information from external sources, execute code, and leverage specialized knowledge to solve complex biomedical problems.
