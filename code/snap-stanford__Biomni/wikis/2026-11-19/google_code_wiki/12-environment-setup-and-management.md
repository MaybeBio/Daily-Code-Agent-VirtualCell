## Environment Setup and Management
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) project requires a specialized bioinformatics environment for its operations. This environment is orchestrated through a set of shell scripts located in the [`/snap-stanford/biomni/biomni_env`](https://github.com/snap-stanford/biomni/biomni_env) directory, designed to manage [`conda`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L30) and [`micromamba`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L21) installations, integrate core bioinformatics tools, install R packages, and configure command-line interface (CLI) tools. The environment setup process handles error conditions and ensures proper environment activation and [`PATH`](https://github.com/snap-stanford/biomni/README.md#L147) variable configuration.

The primary script for setting up the environment is [`/snap-stanford/biomni/biomni_env/setup.sh`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh). This script verifies the presence of either [`conda`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L30) or [`micromamba`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L21) and uses them to install various environments from YAML configuration files. These include a base [`biomni_e1`](https://github.com/snap-stanford/biomni/README.md#L43) environment, core bioinformatics tools, and R packages. The script also handles the installation of additional R packages via [`Rscript`](https://github.com/snap-stanford/biomni/biomni/utils.py#L41). A core functionality of [`/snap-stanford/biomni/biomni_env/setup.sh`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh) is its error handling, which provides robust error management and allows for both interactive and non-interactive installation modes. Upon completion, the script provides guidance on how to activate the environment and configure system [`PATH`](https://github.com/snap-stanford/biomni/README.md#L147) variables.

Managing command-line interface (CLI) tools is handled by the specialized script [`/snap-stanford/biomni/biomni_env/install_cli_tools.sh`](https://github.com/snap-stanford/biomni/biomni_env/install_cli_tools.sh). This script installs and configures bioinformatics tools such as PLINK and IQ-TREE, managing their installation directory and ensuring they are accessible via the system's [`PATH`](https://github.com/snap-stanford/biomni/README.md#L147). It supports adding new tools via a [`cli_tools_config.json`](https://github.com/snap-stanford/biomni/DETAILS.md#L144) file and includes mechanisms for persistent [`PATH`](https://github.com/snap-stanford/biomni/README.md#L147) configuration across shell sessions. For more details on this process, see [Managing Command-Line Interface (CLI) Tools](#environment-setup-and-management-managing-command-line-interface-cli-tools).

For incremental updates and the installation of new software packages and libraries, the project utilizes scripts like [`/snap-stanford/biomni/biomni_env/new_software_v008.sh`](https://github.com/snap-stanford/biomni/biomni_env/new_software_v008.sh). This script automates the installation of various Python packages using [`pip`](https://github.com/snap-stanford/biomni/README.md#L46) and [`uv`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L2211), handles [`git-lfs`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L2211) setup for large files, and integrates [`conda`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L30) installations for specific tools like [`weasyprint`](https://github.com/snap-stanford/biomni/README.md#L234). This modular approach ensures that the environment can be updated efficiently with new dependencies. Further details on this process are available in [Incremental Software Updates and Version Management](#environment-setup-and-management-incremental-software-updates-and-version-management).

The [`/snap-stanford/biomni/biomni_env/README.md`](https://github.com/snap-stanford/biomni/biomni_env/README.md) file serves as a comprehensive guide for users, detailing different installation options based on desired functionality and resource constraints. It covers basic environment setup, full [`E1`](https://github.com/snap-stanford/biomni/README.md#L40) environment configuration, and specialized environments for tasks like copy number analysis. It also provides instructions for activating environments and adding support for additional [`langchain`](https://github.com/snap-stanford/biomni/DETAILS.md#L180) packages.
