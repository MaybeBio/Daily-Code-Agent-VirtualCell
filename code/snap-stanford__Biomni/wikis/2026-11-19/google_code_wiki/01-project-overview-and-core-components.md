## Project Overview and Core Components
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) project functions as an AI agent designed for autonomous biomedical research. It integrates Large Language Models (LLMs) with retrieval-augmented planning and code execution to address problems within the biomedical domain. The system's architecture focuses on orchestrating various AI agents to manage research tasks, dynamically handle resources, and engage in conversational interactions to solve complex biomedical problems.

The core of [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) involves a sophisticated agent orchestration framework. The primary agent, [`A1`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L56), manages the overall workflow, handling configuration, setting up LLMs, and dynamically managing tools and data. This agent's operational flow is built around a [`StateGraph`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L15), which invokes LLMs for reasoning and executes code for practical tasks. Complementing [`A1`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L56), a ReAct agent is implemented using [`LangGraph`](https://github.com/snap-stanford/biomni/biomni/agent/react.py#L265) for managing conversational state, integrating LLMs, and invoking tools. This ReAct agent can dynamically register and configure tools, building its workflow to support reasoning, tool use, and retrieval.

LLM integration is a central component, allowing various LLMs from different providers to be configured and used. A factory function handles the instantiation of these models, supporting dynamic imports and provider-specific configurations. For executing research tasks, [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) includes a [`FunctionGenerator`](https://github.com/snap-stanford/biomni/biomni/agent/function_generator.py#L22) agent that translates natural language into executable Python code. This agent leverages utility functions for safe and efficient execution, supporting languages like R and Bash.

Dynamic resource management and retrieval are key features, where the system intelligently selects relevant tools, data lake items, software libraries, and know-how documents. A [`ToolRetriever`](https://github.com/snap-stanford/biomni/biomni/model/retriever.py#L8) utilizes LLM prompt-based selection to inform the agent's context, ensuring that the most appropriate resources are available for problem-solving. This dynamic approach enables the system to adapt to diverse biomedical queries and research scenarios.
