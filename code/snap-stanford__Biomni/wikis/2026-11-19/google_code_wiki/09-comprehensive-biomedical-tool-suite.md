### Comprehensive Biomedical Tool Suite
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework includes a suite of tools for various biological and medical analyses, categorized by scientific discipline. These tools perform tasks ranging from biochemical data interpretation to complex genomic and cell biology analyses, integrating with external libraries and services.

**Biochemistry** tools, located in [`/snap-stanford/biomni/biomni/tool/biochemistry.py`](https://github.com/snap-stanford/biomni/biomni/tool/biochemistry.py), analyze diverse biochemical data. They process circular dichroism spectra to determine protein secondary structure and thermal stability, analyze RNA secondary structures from dot-bracket notation, and fit enzyme kinetics data to models like [`michaelis_menten`](https://github.com/snap-stanford/biomni/biomni/tool/biochemistry.py#L372) to derive parameters such as [`vmax`](https://github.com/snap-stanford/biomni/biomni/tool/biochemistry.py#L372) and [`km`](https://github.com/snap-stanford/biomni/biomni/tool/biochemistry.py#L319). Additionally, these tools analyze ITC data to quantify binding thermodynamics and perform protein conservation analysis through sequence alignment using [`MuscleCommandline`](https://github.com/snap-stanford/biomni/biomni/tool/genetics.py#L1478) and phylogenetic tree construction.

**Bioengineering** tools, defined in [`/snap-stanford/biomni/biomni/tool/bioengineering.py`](https://github.com/snap-stanford/biomni/biomni/tool/bioengineering.py), handle data for bioengineering applications. They quantify cell migration metrics from time-lapse microscopy using [`tp.locate`](https://github.com/snap-stanford/biomni/biomni/tool/bioengineering.py#L59) and [`tp.link_df`](https://github.com/snap-stanford/biomni/biomni/tool/bioengineering.py#L75), simulate CRISPR-Cas9 genome editing, and analyze neuronal activity from GCaMP imaging data by detecting events and fitting [`exp_decay`](https://github.com/snap-stanford/biomni/biomni/tool/bioengineering.py#L498). Other functions analyze drug release kinetics by fitting models such as [`zero_order`](https://github.com/snap-stanford/biomni/biomni/tool/bioengineering.py#L658) and [`higuchi`](https://github.com/snap-stanford/biomni/biomni/tool/bioengineering.py#L664), quantify myofiber morphology using [`skimage`](https://github.com/snap-stanford/biomni/biomni/tool/pathology.py#L374) functions like [`filters.threshold_otsu`](https://github.com/snap-stanford/biomni/biomni/tool/pathology.py#L655), and decode behavioral variables from neural trajectories using [`PCA`](https://github.com/snap-stanford/biomni/biomni/tool/bioengineering.py#L1088) and [`KalmanFilter`](https://github.com/snap-stanford/biomni/biomni/tool/bioengineering.py#L1087). The toolkit also simulates whole-cell ODE models with [`solve_ivp`](https://github.com/snap-stanford/biomni/biomni/tool/physiology.py#L1129).

**Bioimaging** functionalities, housed in [`/snap-stanford/biomni/biomni/tool/bioimaging.py`](https://github.com/snap-stanford/biomni/biomni/tool/bioimaging.py), provide medical image processing capabilities, particularly for segmentation and registration. The [`SegmentationTool`](https://github.com/snap-stanford/biomni/biomni/tool/bioimaging.py#L30) manages [`nnUNet`](https://github.com/snap-stanford/biomni/biomni/tool/bioimaging.py#L32)-based segmentation, including splitting modalities, preparing input for [`nnUNet`](https://github.com/snap-stanford/biomni/biomni/tool/bioimaging.py#L32), and handling model downloads and environment setup. The [`ImageRegistrationTool`](https://github.com/snap-stanford/biomni/biomni/tool/bioimaging.py#L579) offers [`SimpleITK`](https://github.com/snap-stanford/biomni/biomni/tool/bioimaging.py#L11)-based image registration, encompassing image loading, preprocessing, and the creation of rigid, affine, and deformable transforms, along with similarity metric calculations.

**Biophysics** tools, found in [`/snap-stanford/biomni/biomni/tool/biophysics.py`](https://github.com/snap-stanford/biomni/biomni/tool/biophysics.py), address biophysical analyses such as predicting intrinsically disordered regions in proteins, analyzing cell morphology and cytoskeletal organization from fluorescence microscopy images using [`skimage`](https://github.com/snap-stanford/biomni/biomni/tool/pathology.py#L374) and [`cv2`](https://github.com/snap-stanford/biomni/biomni/tool/pathology.py#L24), and quantifying tissue deformation and flow dynamics from image sequences through [`cv2.calcOpticalFlowPyrLK`](https://github.com/snap-stanford/biomni/biomni/tool/biophysics.py#L402).

**Cancer Biology** analysis tools, within [`/snap-stanford/biomni/biomni/tool/cancer_biology.py`](https://github.com/snap-stanford/biomni/biomni/tool/cancer_biology.py), perform various tasks related to cancer research. They reconstruct and analyze DNA Damage Response (DDR) networks using [`pearsonr`](https://github.com/snap-stanford/biomni/biomni/tool/physiology.py#L431) for interactions and [`degree_centrality`](https://github.com/snap-stanford/biomni/biomni/tool/cancer_biology.py#L138) for identifying hub genes, quantify cell senescence and apoptosis from flow cytometry data using [`FCMeasurement`](https://github.com/snap-stanford/biomni/biomni/tool/immunology.py#L1010) and gating, and detect and annotate somatic mutations by orchestrating external tools like [`gatk Mutect2`](https://github.com/snap-stanford/biomni/biomni/tool/cancer_biology.py#L427) and [`snpEff`](https://github.com/snap-stanford/biomni/biomni/tool/cancer_biology.py#L515). Other capabilities include detecting structural variations using [`lumpyexpress`](https://github.com/snap-stanford/biomni/biomni/tool/cancer_biology.py#L677) and [`bcftools`](https://github.com/snap-stanford/biomni/biomni/tool/cancer_biology.py#L705), applying Non-negative Matrix Factorization (NMF) to gene expression data for tumor subtyping, and analyzing copy number variations and tumor purity with tools like [`cnvkit`](https://github.com/snap-stanford/biomni/docs/known_conflicts.md#L16).

**Cell Biology** functions, located in [`/snap-stanford/biomni/biomni/tool/cell_biology.py`](https://github.com/snap-stanford/biomni/biomni/tool/cell_biology.py), perform cell-level analyses. These include quantifying cell cycle phases from microscopy images, tracking cell motility and clustering patterns using [`KMeans`](https://github.com/snap-stanford/biomni/biomni/tool/cell_biology.py#L185), simulating FACS-based cell sorting, and immunophenotyping flow cytometry data with [`FlowCytometryTools`](https://github.com/snap-stanford/biomni/biomni/tool/immunology.py#L1001). Additionally, they quantify mitochondrial morphology and membrane potential from paired fluorescence microscopy images.

**Genetics** tools, detailed in [`/snap-stanford/biomni/biomni/tool/genetics.py`](https://github.com/snap-stanford/biomni/biomni/tool/genetics.py), provide utilities for genomic and genetic analysis. These tools perform genomic coordinate liftover using [`pyliftover`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L91), implement Bayesian fine-mapping with deep variational inference, analyze CRISPR-Cas9 mutation outcomes by sequence alignment with [`pairwise2.align.globalms`](https://github.com/snap-stanford/biomni/biomni/tool/genetics.py#L391), and simulate demographic histories using [`msprime`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L160). They also identify transcription factor binding sites using JASPAR PWMs, fit genomic prediction models using linear mixed models, and simulate PCR and gel electrophoresis. Protein phylogeny analysis is performed using [`MuscleCommandline`](https://github.com/snap-stanford/biomni/biomni/tool/genetics.py#L1478) and [`iqtree`](https://github.com/snap-stanford/biomni/biomni/tool/genetics.py#L1465).

**Genomics** capabilities, in [`/snap-stanford/biomni/biomni/tool/genomics.py`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py), include various bioinformatics tools for single-cell RNA sequencing (scRNA-seq) analysis, gene annotation, and genomic interaction analysis. These tools facilitate unsupervised cell type transfer between scRNA-seq datasets using [`popv`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L43), interspecies gene conversion via [`pybiomart`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L12), and the generation of gene embeddings with ESM models. Cell type annotation in scRNA-seq data is supported through [`leiden`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L468) clustering and LLM-based prediction, as well as hierarchical annotation using [`panhumanpy`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L108). The toolkit also generates [`scvi`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L98) and [`harmony`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L130) embeddings, maps cells to the IMA reference, fetches RNA-seq data from ARCHS4 using [`gget.archs4`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L992), and performs gene set enrichment analysis with [`gget.enrichr`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L1061). Other functions analyze Hi-C data for chromatin interactions, perform comparative genomics using [`bwa`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L198), call ChIP-seq peaks with [`macs2`](https://github.com/snap-stanford/biomni/DETAILS.md#L291), discover motifs with [`HOMER`](https://github.com/snap-stanford/biomni/biomni/tool/genomics.py#L1803), and analyze genomic region overlaps using [`pybedtools`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L107). It also generates State embeddings for single-cell RNA-seq data using the SE-600M model.

**Glycoengineering** utilities, in [`/snap-stanford/biomni/biomni/tool/glycoengineering.py`](https://github.com/snap-stanford/biomni/biomni/tool/glycoengineering.py), focus on analyzing protein sequences for glycosylation motifs and hotspots. These functions, designed to be dependency-light, scan for N-linked glycosylation sequons and predict O-glycosylation hotspots based on serine/threonine density.

**Immunology** tools, within [`/snap-stanford/biomni/biomni/tool/immunology.py`](https://github.com/snap-stanford/biomni/biomni/tool/immunology.py), analyze immunology-related experimental data. They orchestrate ATAC-seq differential accessibility pipelines using [`macs2`](https://github.com/snap-stanford/biomni/DETAILS.md#L291), analyze bacterial growth curves by fitting [`logistic_growth`](https://github.com/snap-stanford/biomni/biomni/tool/immunology.py#L224) models, and simulate immune cell isolation and purification, including MACS. Functions also estimate cell cycle phase durations from flow cytometry data using [`minimize`](https://github.com/snap-stanford/biomni/biomni/tool/immunology.py#L584) and [`simulate_cell_population`](https://github.com/snap-stanford/biomni/biomni/tool/immunology.py#L529), track immune cells under flow conditions using [`cv2`](https://github.com/snap-stanford/biomni/biomni/tool/pathology.py#L24) and [`trackpy`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L149), and quantify CFSE cell proliferation using [`FlowCytometryTools`](https://github.com/snap-stanford/biomni/biomni/tool/immunology.py#L1001). Further analyses include quantifying cytokine production in CD4+ T cells, analyzing EBV antibody titers from ELISA data, and analyzing CNS lesion histology and immunohistochemistry images using [`scikit-image`](https://github.com/snap-stanford/biomni/DETAILS.md#L283).

**Microbiology** analysis and simulation tools are available in [`/snap-stanford/biomni/biomni/tool/microbiology.py`](https://github.com/snap-stanford/biomni/biomni/tool/microbiology.py). They optimize anaerobic digestion processes, analyze arsenic speciation, count bacterial colonies from images using [`cv2`](https://github.com/snap-stanford/biomni/biomni/tool/pathology.py#L24), annotate bacterial genomes with [`prokka`](https://github.com/snap-stanford/biomni/biomni/tool/microbiology.py#L537), and enumerate bacterial CFU by serial dilution. These tools also model bacterial growth dynamics using [`logistic_growth`](https://github.com/snap-stanford/biomni/biomni/tool/immunology.py#L224) ODEs, quantify biofilm biomass, segment and analyze microbial cells using [`skimage`](https://github.com/snap-stanford/biomni/biomni/tool/pathology.py#L374) functions like [`watershed`](https://github.com/snap-stanford/biomni/biomni/tool/pathology.py#L833) and [`measure.regionprops_table`](https://github.com/snap-stanford/biomni/biomni/tool/biophysics.py#L202), and simulate generalized Lotka-Volterra dynamics using [`odeint`](https://github.com/snap-stanford/biomni/biomni/tool/microbiology.py#L1295). RNA secondary structure prediction with ViennaRNA's [`RNA.fold`](https://github.com/snap-stanford/biomni/biomni/tool/microbiology.py#L1383) and microbial population dynamics simulation using the Gillespie algorithm are also supported.

**Molecular Biology** operations are performed by tools in [`/snap-stanford/biomni/biomni/tool/molecular_biology.py`](https://github.com/snap-stanford/biomni/biomni/tool/molecular_biology.py). These include annotating open reading frames, annotating plasmids using external tools like [`plannotate`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L217), retrieving gene coding sequences and plasmid sequences from NCBI Entrez and Addgene, aligning sequences using [`pairwise2`](https://github.com/snap-stanford/biomni/biomni/tool/genetics.py#L351), and simulating PCR and restriction enzyme digestion. They also find restriction sites, identify restriction enzymes, detect sequence mutations, design knockout sgRNAs, and design various primers for PCR, Golden Gate assembly, and Sanger sequencing. Additionally, the framework can generate step-by-step laboratory protocols.

The framework also includes dedicated modules for database querying, lab automation, and literature searching. The **Database** tools in [`/snap-stanford/biomni/biomni/tool/database.py`](https://github.com/snap-stanford/biomni/biomni/tool/database.py) facilitate querying biological and medical databases like UniProt, AlphaFold, InterPro, PDB, KEGG, STRING, and others by translating natural language prompts into structured API calls via an LLM. **Lab Automation** tools, located in [`/snap-stanford/biomni/biomni/tool/lab_automation.py`](https://github.com/snap-stanford/biomni/biomni/tool/lab_automation.py), provide utilities for PyLabRobot documentation access and script testing in a simulated environment. The **Literature** tools in [`/snap-stanford/biomni/biomni/tool/literature.py`](https://github.com/snap-stanford/biomni/biomni/tool/literature.py) support academic research by enabling queries to [`arxiv`](https://github.com/snap-stanford/biomni/biomni/env_desc.py#L142), Google Scholar, PubMed, and general web searches, as well as extracting content from URLs and PDFs. An example [`FastMCP`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L2004) service for PubMed is provided in [`/snap-stanford/biomni/biomni/tool/example_mcp_tools/pubmed_mcp.py`](https://github.com/snap-stanford/biomni/biomni/tool/example_mcp_tools/pubmed_mcp.py) for searching articles and retrieving abstracts.
