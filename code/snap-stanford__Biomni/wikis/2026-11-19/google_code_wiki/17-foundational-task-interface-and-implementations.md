### Foundational Task Interface and Implementations
The [`base_task`](https://github.com/snap-stanford/biomni/biomni/task/base_task.py#L1) abstract interface provides a standardized structure for various tasks within the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework. This interface, defined in [`/snap-stanford/biomni/biomni/task/base_task.py`](https://github.com/snap-stanford/biomni/biomni/task/base_task.py), requires implementations for task initialization, example retrieval, iteration over datasets, and evaluation of results. A key method, [`get_prompt_from_input`](https://github.com/snap-stanford/biomni/biomni/task/base_task.py#L17), offers a default mechanism for generating prompts by expecting a "prompt" key from the [`get_example`](https://github.com/snap-stanford/biomni/biomni/task/hle.py#L103) method, thus streamlining prompt creation across different tasks.

Concrete implementations of this interface include tasks for multiple-choice question datasets. For instance, the [`humanity_last_exam`](https://github.com/snap-stanford/biomni/biomni/task/hle.py#L14) class in [`/snap-stanford/biomni/biomni/task/hle.py`](https://github.com/snap-stanford/biomni/biomni/task/hle.py) handles questions from the "Humanity's Last Exam" dataset. It loads and filters data from a Parquet file, extracts questions and correct letter answers, and provides methods to retrieve individual examples or iterate through the entire dataset. This class also defines an [`evaluate`](https://github.com/snap-stanford/biomni/biomni/task/hle.py#L119) method to calculate metrics such as accuracy, coverage, and precision for model responses, and specifies a Pydantic [`BaseModel`](https://github.com/snap-stanford/biomni/biomni/utils.py#L21) for structured output.

Similarly, the [`lab_bench`](https://github.com/snap-stanford/biomni/biomni/task/lab_bench.py#L14) class in [`/snap-stanford/biomni/biomni/task/lab_bench.py`](https://github.com/snap-stanford/biomni/biomni/task/lab_bench.py) manages multiple-choice biology questions from another Parquet dataset. It loads and processes question data, dynamically shuffles options (including a "Insufficient information" choice), and formats prompts with specific tags to guide language model responses. Like [`humanity_last_exam`](https://github.com/snap-stanford/biomni/biomni/task/hle.py#L14), it offers example retrieval, iteration, and an [`evaluate`](https://github.com/snap-stanford/biomni/biomni/task/hle.py#L119) method to assess model performance with metrics like accuracy, coverage, and refrain ratio. It also utilizes a Pydantic [`BaseModel`](https://github.com/snap-stanford/biomni/biomni/utils.py#L21) for structured parsing of model outputs, ensuring consistency in how results are handled.
