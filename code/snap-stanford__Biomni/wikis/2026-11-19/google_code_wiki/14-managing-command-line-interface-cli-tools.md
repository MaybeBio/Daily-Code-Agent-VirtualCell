### Managing Command-Line Interface (CLI) Tools
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) environment setup includes robust mechanisms for installing and managing command-line interface (CLI) bioinformatics tools. This functionality is primarily handled by the [`/snap-stanford/biomni/biomni_env/install_cli_tools.sh`](https://github.com/snap-stanford/biomni/biomni_env/install_cli_tools.sh) script, which orchestrates the download, installation, and configuration of various tools such as [`PLINK`](https://github.com/snap-stanford/biomni/DETAILS.md#L291) and [`IQ-TREE`](https://github.com/snap-stanford/biomni/DETAILS.md#L291).

The [`install_cli_tools.sh`](https://github.com/snap-stanford/biomni/DETAILS.md#L62) script automates the process of obtaining these tools, often involving fetching binaries, compiling source code, or executing specialized installers. It ensures that the tools are placed in a designated [`biomni_tools`](https://github.com/snap-stanford/biomni/MANIFEST.in#L9) directory and that their executables are discoverable by the system through proper [`PATH`](https://github.com/snap-stanford/biomni/README.md#L147) variable configuration. This configuration includes adding the tools' binary directory to the current shell session's [`PATH`](https://github.com/snap-stanford/biomni/README.md#L147) and persistently modifying user profile files (e.g., [`.bashrc`](https://github.com/snap-stanford/biomni/biomni_env/install_cli_tools.sh#L550), [`.zshrc`](https://github.com/snap-stanford/biomni/biomni_env/install_cli_tools.sh#L555)) to maintain access across sessions. To simplify this, a [`setup_path.sh`](https://github.com/snap-stanford/biomni/DETAILS.md#L63) script is generated to manage [`PATH`](https://github.com/snap-stanford/biomni/README.md#L147) modifications.

A key design choice for tool management is the use of a configuration-driven approach. Tool metadata, including download Uniform Resource Locators (URLs), expected binary paths, and commands for version verification, are stored in a [`cli_tools_config.json`](https://github.com/snap-stanford/biomni/DETAILS.md#L144) file. This allows for flexible addition and updating of new tools without altering the core script logic. The script is also platform-aware, differentiating between Linux, macOS Intel, and macOS ARM64 architectures to retrieve the correct binaries. The overall environment setup is detailed further in [Orchestrating the Environment Setup with `setup.sh`](#environment-setup-and-management-orchestrating-the-environment-setup-with-setupsh).
