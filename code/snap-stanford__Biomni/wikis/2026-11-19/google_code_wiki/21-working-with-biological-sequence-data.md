### Working with Biological Sequence Data
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework facilitates the handling and utilization of raw biological sequence data for various bioinformatics tools. An example of such data is provided in the file [`/snap-stanford/biomni/tutorials/examples/plentiCRISPR.txt`](https://github.com/snap-stanford/biomni/tutorials/examples/plentiCRISPR.txt). This file contains a raw sequence of nucleotides, typically DNA (composed of 'A', 'C', 'G', 'T'), which can serve as input for further analysis within the system. This type of raw data is fundamental for various bioinformatics tasks, including sequence alignment, gene prediction, or primer design, which can then be processed by the comprehensive suite of [Biomedical Tools and Resources](#biomedical-tools-and-resources) available in [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25).
