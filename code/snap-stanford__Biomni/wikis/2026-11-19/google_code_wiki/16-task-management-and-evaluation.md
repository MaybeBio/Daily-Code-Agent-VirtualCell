## Task Management and Evaluation
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework provides a structured approach to defining, managing, and evaluating various research tasks, particularly those involving question answering and information extraction within the biomedical domain. This system enables the agent to interact with diverse datasets and assess its performance against established benchmarks.

At its core, [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) uses a foundational interface for tasks, defined in [`base_task.py`](https://github.com/snap-stanford/biomni/DETAILS.md#L92), which specifies abstract methods for task initialization, example retrieval, data iteration, and evaluation. This interface ensures consistency across different task implementations. Concrete examples include handling multiple-choice question datasets, such as "Humanity's Last Exam" (HLE) as implemented in [`/snap-stanford/biomni/biomni/task/hle.py`](https://github.com/snap-stanford/biomni/biomni/task/hle.py) and biology-related questions in [`/snap-stanford/biomni/biomni/task/lab_bench.py`](https://github.com/snap-stanford/biomni/biomni/task/lab_bench.py). These implementations manage data loading from parquet files, process questions and answer choices, generate prompts for language models, and evaluate responses based on metrics like accuracy, coverage, and precision. The output is structured using Pydantic [`BaseModel`](https://github.com/snap-stanford/biomni/biomni/utils.py#L21)s, ensuring consistency for downstream processing.

For evaluating the agent's performance, the [`BiomniEval1`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py#L14) benchmark, detailed in [`/snap-stanford/biomni/biomni/eval/biomni_eval1.py`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py), offers a unified interface. This class loads a comprehensive dataset of task instances and provides methods to evaluate user answers against ground truth. The [`_compute_reward`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py#L71) method within [`BiomniEval1`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py#L14) encapsulates task-specific scoring logic, which can vary from simple string comparisons for tasks like CRISPR delivery and GWAS variant prioritization to complex JSON parsing for rare disease diagnosis or patient gene detection. This modular design allows for the extension of evaluation criteria to accommodate new types of biomedical problems.

Beyond predefined benchmarks, [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) also incorporates capabilities for extracting novel tasks directly from scientific literature. Scripts located in the [`/snap-stanford/biomni/biomni/biorxiv_scripts`](https://github.com/snap-stanford/biomni/biomni/biorxiv_scripts) directory, such as [`extract_biorxiv_tasks.py`](https://github.com/snap-stanford/biomni/DETAILS.md#L84), leverage LLM-based agents to analyze bioRxiv papers. This process involves downloading PDFs, extracting text, and then identifying common tasks, databases, and software mentioned within the papers. The extracted information is then summarized, generating insights into emerging research areas and potential new tasks for the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) agent. Furthermore, the [`generate_function.py`](https://github.com/snap-stanford/biomni/DETAILS.md#L85) script in the same directory demonstrates how these extracted task descriptions can be used to generate Python functions automatically, facilitating the expansion of the agent's capabilities.
