### Lab Automation and Literature Tools
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework incorporates specialized tools for interacting with literature databases and facilitating lab automation. For academic research, the system offers functionality to search and retrieve information from platforms like PubMed. An example of this capability is demonstrated by the services provided in [`/snap-stanford/biomni/biomni/tool/example_mcp_tools/pubmed_mcp.py`](https://github.com/snap-stanford/biomni/biomni/tool/example_mcp_tools/pubmed_mcp.py), which exposes methods for searching PubMed articles and retrieving their abstracts. This is achieved by utilizing the Entrez library to communicate with NCBI databases. The data is structured using [`BaseModel`](https://github.com/snap-stanford/biomni/biomni/utils.py#L21) to define article information, ensuring consistency and validation. For instance, the [`search_pubmed`](https://github.com/snap-stanford/biomni/biomni/tool/example_mcp_tools/pubmed_mcp.py#L20) tool performs a query, returning structured [`Article`](https://github.com/snap-stanford/biomni/biomni/tool/example_mcp_tools/pubmed_mcp.py#L11) objects containing details such as PMID, title, journal, and year, while the [`get_article_abstract`](https://github.com/snap-stanford/biomni/biomni/tool/example_mcp_tools/pubmed_mcp.py#L32) tool retrieves the abstract for a specified article. These tools are registered as callable services using [`FastMCP`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L2004), enabling their remote invocation and integration into broader research workflows. While the description of lab automation tools, such as dynamic documentation access and script testing for PyLabRobot, is mentioned in the overall plan, the provided summaries do not contain specific details for this aspect within [`/snap-stanford/biomni/biomni/tool/example_mcp_tools`](https://github.com/snap-stanford/biomni/biomni/tool/example_mcp_tools).
