### Orchestrating the Environment Setup with `setup.sh`
The primary orchestration script for setting up the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) environment is [`/snap-stanford/biomni/biomni_env/setup.sh`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh). This script automates the installation of various components necessary for the biomedical AI agent, including Conda/micromamba environments, core bioinformatics tools, R packages, and command-line interface (CLI) tools. The process begins with verifying the presence of either [`conda`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L30) or [`micromamba`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L21), ensuring the foundational package management system is available.

The script manages environment installations from YAML files, such as [`environment.yml`](https://github.com/snap-stanford/biomni/DETAILS.md#L60) for the base [`biomni_e1`](https://github.com/snap-stanford/biomni/README.md#L43) environment, [`bio_env.yml`](https://github.com/snap-stanford/biomni/DETAILS.md#L60) for core bioinformatics tools, and [`r_packages.yml`](https://github.com/snap-stanford/biomni/DETAILS.md#L61) for R packages. It integrates CLI tools by invoking [`/snap-stanford/biomni/biomni_env/install_cli_tools.sh`](https://github.com/snap-stanford/biomni/biomni_env/install_cli_tools.sh), which handles the specific installation and PATH configuration for tools like PLINK and IQ-TREE. The script also includes error handling mechanisms to manage installation failures and supports both interactive and non-interactive modes, allowing for either guided setup or automated deployment. After installation, it provides instructions for activating the environment and correctly configuring the system's PATH. For a detailed discussion of the CLI tool management, see [Managing Command-Line Interface (CLI) Tools](#environment-setup-and-management-managing-command-line-interface-cli-tools).
