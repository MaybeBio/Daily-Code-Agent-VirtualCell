## Tutorials and Examples
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework provides practical examples and tutorials to guide users in applying its capabilities to biomedical problems. These resources demonstrate how to work with biological sequence data and illustrate the setup, execution, and testing of a Multi-Component Protocol (MCP) server.

One area of focus is handling raw biological sequence data. For instance, the file [`/snap-stanford/biomni/tutorials/examples/plentiCRISPR.txt`](https://github.com/snap-stanford/biomni/tutorials/examples/plentiCRISPR.txt) contains DNA nucleotides that can serve as input for various bioinformatics tools within the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) framework. This provides a tangible example for users to understand how external data can be integrated into the system for analysis.

Another practical demonstration involves the operation of a Biomni MCP server. The [`run_mcp_server.py`](https://github.com/snap-stanford/biomni/docs/mcp_integration.md#L268) script, located in [`/snap-stanford/biomni/tutorials/examples/expose_biomni_server/run_mcp_server.py`](https://github.com/snap-stanford/biomni/tutorials/examples/expose_biomni_server/run_mcp_server.py), shows how to initialize and run such a server. This server is configured to expose database-related [`tool_modules`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L1995) and uses standard I/O for communication. Complementing this, the [`test_mcp_server.py`](https://github.com/snap-stanford/biomni/docs/mcp_integration.md#L211) script in [`/snap-stanford/biomni/tutorials/examples/expose_biomni_server/test_mcp_server.py`](https://github.com/snap-stanford/biomni/tutorials/examples/expose_biomni_server/test_mcp_server.py) acts as a client. It connects to the running MCP server, lists the available tools, and demonstrates how to invoke a specified tool with provided arguments, subsequently parsing and displaying the results. This setup illustrates the client-server interaction model and the process of tool discovery and execution within the [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) ecosystem.
