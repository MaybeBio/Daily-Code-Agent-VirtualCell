# snap-stanford/biomni Overview
The [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) project implements an AI agent for autonomous biomedical research, integrating large language models with retrieval-augmented planning and code execution. It orchestrates various AI agents to manage research tasks, dynamically handle resources, and engage in conversational interactions to solve complex biomedical problems.

The system's architecture centers on agent orchestration. A primary agent, [`A1`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L56), manages the overall workflow, handling configuration, setting up language models, and dynamically managing tools and data. Its operational flow uses a [`StateGraph`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L15) for iterative planning, execution, and observation. A complementary ReAct agent uses [`LangGraph`](https://github.com/snap-stanford/biomni/biomni/agent/react.py#L265) to manage conversational state, integrate language models, and dynamically invoke tools. Further details on agent architecture are available in [Biomni Agent (A1) Architecture and Workflow](#project-overview-and-core-components-biomni-agent-a1-architecture-and-workflow) and [ReAct Agent Implementation and State Management](#project-overview-and-core-components-react-agent-implementation-and-state-management).

Language model integration allows various LLMs from different providers to be configured and used through a factory function. This enables dynamic imports and provider-specific configurations. The system includes a [`FunctionGenerator`](https://github.com/snap-stanford/biomni/biomni/agent/function_generator.py#L22) agent that translates natural language into executable Python code. Utility functions support safe and efficient execution across languages like R and Bash. For more information, see [LLM Integration and Configuration](#project-overview-and-core-components-llm-integration-and-configuration) and [Code Generation and Execution](#project-overview-and-core-components-code-generation-and-execution).

Dynamic resource management and retrieval are key features. The [`ToolRetriever`](https://github.com/snap-stanford/biomni/biomni/model/retriever.py#L8) intelligently selects relevant tools, data lake items, software libraries, and know-how documents based on user queries. This process uses LLM prompt-based selection to inform the agent's context. [Dynamic Resource Management and Retrieval](#project-overview-and-core-components-dynamic-resource-management-and-retrieval) provides additional details.

[`biomni`](https://github.com/snap-stanford/biomni/README.md#L25) provides an array of tools and resources for biomedical analyses. These include a comprehensive suite of domain-specific tools, organized by scientific discipline. It also manages a collection of structured know-how documents and protocols. [Biomedical Tools and Resources](#biomedical-tools-and-resources) further describes these capabilities.

A specialized bioinformatics environment is required for [`biomni`](https://github.com/snap-stanford/biomni/README.md#L25)'s operations. Shell scripts manage [`conda`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L30) and [`micromamba`](https://github.com/snap-stanford/biomni/biomni_env/setup.sh#L21) installations, integrate core bioinformatics tools, and configure command-line interface tools. These scripts handle error conditions and ensure proper environment activation and [`PATH`](https://github.com/snap-stanford/biomni/README.md#L147) variable configuration. Refer to [Environment Setup and Management](#environment-setup-and-management) for more information.

The framework supports defining, managing, and evaluating research tasks. It uses a foundational interface for tasks, with implementations for question-answering datasets. A benchmark, [`BiomniEval1`](https://github.com/snap-stanford/biomni/biomni/eval/biomni_eval1.py#L14), offers a unified interface for assessing model responses against ground truth. The system also extracts novel tasks from scientific literature using LLM-based agents. Task management and evaluation details are in [Task Management and Evaluation](#task-management-and-evaluation).
