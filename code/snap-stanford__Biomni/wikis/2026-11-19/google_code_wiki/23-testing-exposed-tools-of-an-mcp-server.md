### Testing Exposed Tools of an MCP Server
The [`test_mcp_server.py`](https://github.com/snap-stanford/biomni/docs/mcp_integration.md#L211) script in [`/snap-stanford/biomni/tutorials/examples/expose_biomni_server/test_mcp_server.py`](https://github.com/snap-stanford/biomni/tutorials/examples/expose_biomni_server/test_mcp_server.py) provides a client-side mechanism for validating the functionality of individual tools exposed by a Biomni Multi-Component Protocol (MCP) server. This script connects to a local server instance (typically launched by [`run_mcp_server.py`](https://github.com/snap-stanford/biomni/docs/mcp_integration.md#L268) in the same directory) via standard input/output (stdio) and performs a series of actions to test a designated tool.

The testing process begins by establishing a connection to the server. The client then discovers the tools available on the server by listing them. Once a [`target_tool`](https://github.com/snap-stanford/biomni/tutorials/examples/expose_biomni_server/test_mcp_server.py#L70) is identified (configured via the [`TOOL_TO_TEST`](https://github.com/snap-stanford/biomni/tutorials/examples/expose_biomni_server/test_mcp_server.py#L14) constant), the script displays its key characteristics, including its name, description, and the schema of its input parameters. Subsequently, the script invokes this tool using predefined arguments ([`TEST_ARGS`](https://github.com/snap-stanford/biomni/tutorials/examples/expose_biomni_server/test_mcp_server.py#L15)) and processes the result. Results are typically expected in JSON format, which the script parses and displays in a structured manner. The script also incorporates robust error handling, providing informative messages and suggestions, particularly for issues related to parameter validation during tool invocation. This client-side interaction leverages [`stdio_client`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L378) and [`ClientSession`](https://github.com/snap-stanford/biomni/biomni/agent/a1.py#L377) for managing the asynchronous communication with the server and executing tool calls. More details on the MCP server setup can be found in [Setting up and Running a Multi-Component Protocol (MCP) Server](#tutorials-and-examples-setting-up-and-running-a-multi-component-protocol-mcp-server).
