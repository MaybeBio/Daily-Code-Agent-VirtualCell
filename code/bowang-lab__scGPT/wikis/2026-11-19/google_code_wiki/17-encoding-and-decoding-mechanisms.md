### Encoding and Decoding Mechanisms
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) repository utilizes a modular approach for processing single-cell and multi-omic gene expression data, employing a suite of encoding and decoding mechanisms. These modules transform raw biological data into a format suitable for transformer models and then interpret the model's output back into meaningful biological predictions.

### Encoders

The encoding modules convert different types of input data into dense numerical representations (embeddings) that the transformer models can process.

*   **[`GeneEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L717)**: This module, found in files such as [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), maps discrete gene identifiers into continuous vector embeddings. This is analogous to word embeddings in natural language processing, where each gene is assigned a unique vector that captures its characteristics within the biological context. A [`nn.LayerNorm`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L645) is applied after the embedding for normalization.
*   **[`ContinuousValueEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L759)**: Located in [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), this encoder transforms continuous numerical values, such as gene expression levels, into embeddings. It typically uses multiple [`nn.Linear`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L641) layers with [`nn.ReLU`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L768) activations and [`nn.LayerNorm`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L645) to process these values, optionally clipping input values to a maximum range.
*   **[`CategoryValueEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L789)**: Also defined in [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), this module is used for categorical numerical values, such as binned gene expression values. Similar to [`GeneEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L717), it uses [`nn.Embedding`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L725) to map these categories to vectors.
*   **[`BatchLabelEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L809)**: In [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), this encoder handles batch or modality labels, converting them into embeddings. This allows the model to incorporate information about the origin or type of data sample, which can be crucial for mitigating technical variations (batch effects).
*   **[`pert_encoder`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py#L80)**: Specifically used in generative models like [`TransformerGenerator`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py#L27) in [`/bowang-lab/scgpt/scgpt/model/generation_model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py), this encoder embeds perturbation flags. These flags indicate whether a cell or gene has undergone a specific perturbation (e.g., control, drug treatment), enabling the model to learn and predict the effects of such interventions.

### Decoders

The decoding modules interpret the transformer model's processed embeddings to generate specific predictions or outputs related to the biological tasks.

*   **[`ExprDecoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L842)**: Found in [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), this decoder is responsible for predicting gene expression values. It takes the transformer's output and uses a multi-layer perceptron ([`self.fc`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L851)) to estimate expression. It can also model an explicit zero probability ([`self.zero_logit`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L860)), which is important for handling the sparsity common in single-cell gene expression data.
*   **[`AffineExprDecoder`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py#L373)**: Defined in [`/bowang-lab/scgpt/scgpt/model/generation_model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py), this is a specialized expression decoder used in generative models. It predicts gene expression values using an affine transformation of the form [`Ax + b`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L93), where [`A`](https://github.com/bowang-lab/scgpt/LICENSE#L17) and [`b`](https://github.com/bowang-lab/scgpt/docs/make.bat#L23) are generated by internal [`ExprDecoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L842) instances. This allows for more flexible and interpretable modeling of gene expression, including handling explicit zero probabilities and adaptive biases.
*   **[`ClsDecoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L884)**: In [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), this decoder performs classification tasks, typically for cell types. It uses an MLP with [`nn.Linear`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L641) layers and [`nn.LayerNorm`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L645) to map a cell-level embedding (derived from the transformer's output) to a probability distribution over predefined cell classes.
*   **[`MVCDecoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L915)**: This decoder, located in [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), handles Masked Value Prediction. It combines cell and gene embeddings to predict values that were masked during training. It supports various architectural styles (e.g., "inner product", "concat query", "sum query") for combining these embeddings and can also predict explicit zero probabilities.
