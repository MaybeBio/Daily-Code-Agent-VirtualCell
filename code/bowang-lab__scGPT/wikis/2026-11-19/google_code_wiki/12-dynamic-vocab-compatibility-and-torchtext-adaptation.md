### Dynamic Vocab Compatibility and `torchtext` Adaptation
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) project maintains compatibility with varying [`torchtext`](https://github.com/bowang-lab/scgpt/docs/environment.yml#L19) [`Vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L251) API versions through the [`/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py) module. This module addresses changes in [`torchtext`](https://github.com/bowang-lab/scgpt/docs/environment.yml#L19) where [`Vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L251) became a non-subclassable C++ extension in versions 0.14 and later, which impacts the ability to extend its functionality.

To ensure a consistent [`Vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L251) interface regardless of the [`torchtext`](https://github.com/bowang-lab/scgpt/docs/environment.yml#L19) version, [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) dynamically checks if [`torchtext.vocab.Vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L14) can be subclassed. This check is performed by [`_probe_torchtext_vocab_subclassable`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L36). If it can, the system leverages the native [`torchtext`](https://github.com/bowang-lab/scgpt/docs/environment.yml#L19) [`Vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L251) class. If not, a pure-Python fallback implementation named [`BuiltinVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L81) is used instead. This [`BuiltinVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L81) class provides a compatible public API for token-to-index and index-to-token mappings, handling out-of-vocabulary tokens, and supporting token manipulation. This approach allows the [`GeneVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L24) class to operate seamlessly across different [`torchtext`](https://github.com/bowang-lab/scgpt/docs/environment.yml#L19) environments without requiring modifications to its core logic, thereby maintaining stability and flexibility in vocabulary management. Further details on [`GeneVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L24) can be found in [GeneVocab Class: Core Vocabulary Management](#gene-tokenization-and-vocabulary-genevocab-class-core-vocabulary-management).
