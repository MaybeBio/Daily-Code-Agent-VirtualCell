### Fine-tuning an scGPT Model with Adversarial Batch Alignment
Fine-tuning an scGPT model involves adapting a pre-trained transformer model to specific single-cell RNA sequencing (scRNA-seq) datasets, incorporating techniques such as masked gene modeling and adversarial batch alignment for improved performance and batch effect correction. The workflow is demonstrated in [`/bowang-lab/scgpt/examples/finetune_integration.py`](https://github.com/bowang-lab/scgpt/examples/finetune_integration.py).

The process begins with data preparation, where raw scRNA-seq data undergoes preprocessing steps including gene filtering, normalization, log-transformation, identification of highly variable genes, and expression value binning. This transforms the data into a format suitable for the [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) model. After preprocessing, gene expression data is tokenized, converting gene names into numerical IDs and padding sequences to uniform lengths, as described in [Gene Tokenization and Vocabulary](#gene-tokenization-and-vocabulary).

The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) model, typically a [`TransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L21), is initialized with specific architectural parameters and can optionally load a pre-trained version. During training, the model uses multiple loss components. Masked gene modeling, analogous to Masked Language Modeling (MLM), involves predicting masked gene expression values, utilizing [`masked_mse_loss`](https://github.com/bowang-lab/scgpt/scgpt/loss.py#L5) and [`criterion_neg_log_bernoulli`](https://github.com/bowang-lab/scgpt/scgpt/loss.py#L16) for zero probability prediction. This helps the model learn gene relationships and context. Adversarial batch alignment employs [`criterion_dab`](https://github.com/bowang-lab/scgpt/examples/finetune_integration.py#L429) to mitigate batch effects, which are technical variations introduced during data collection. This involves a discriminator that tries to distinguish between different batches, while the model simultaneously tries to confuse the discriminator, thereby learning batch-invariant representations. This approach is further detailed in [Adversarial Domain Adaptation and Batch Effect Correction](#model-architectures-and-training-adversarial-domain-adaptation-and-batch-effect-correction).

Evaluation of the fine-tuned model includes assessing performance on a validation set using metrics such as [`masked_mse_loss`](https://github.com/bowang-lab/scgpt/scgpt/loss.py#L5) and [`masked_relative_error`](https://github.com/bowang-lab/scgpt/scgpt/loss.py#L28). Beyond these quantitative metrics, the [`eval_testdata`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L589) function generates cell embeddings, which are then used to compute biological conservation metrics using [`scib`](https://github.com/bowang-lab/scgpt/README.md#L99) metrics and to visualize data with UMAP plots. These visualizations often illustrate how well the model has integrated different batches and preserved biological distinctions. This comprehensive evaluation ensures that the model not only accurately predicts gene expression but also generates biologically meaningful and batch-corrected cell representations. The utilities for evaluating these metrics are part of the general utilities for single-cell genomics workflows, as discussed in [Utility Functions and Diagnostics](#utility-functions-and-diagnostics). Experiment tracking and saving of models are managed through [`wandb`](https://github.com/bowang-lab/scgpt/README.md#L40) for reproducibility.
