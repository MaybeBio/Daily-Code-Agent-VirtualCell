## Data Management and Preprocessing
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) project employs a robust data management system to process large-scale single-cell and multi-omic gene expression datasets. This system encompasses data access, pretraining, annotation, integration, perturbation prediction, gene regulatory network (GRN) analysis, and zero-shot integration. It is designed to handle [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects and organize datasets into a structured repository.

A central aspect of [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1)'s data management involves building a pre-training cell corpus from the Cellxgene Census. This process includes defining queries, indexing [`soma_joinid`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L37)s, chunked downloading of data, converting data to the [`scb`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L49) format, and parallel processing using SLURM for efficient, large-scale data ingestion. The pipeline also supports advanced filtering mechanisms, such as filtering for specific cancer types.

The primary datasets used in the [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) manuscript are organized within the [`/bowang-lab/scgpt/data`](https://github.com/bowang-lab/scgpt/data) directory. This includes pretraining data, as well as datasets tailored for cell type annotation, multi-batch and multi-omics integration, perturbation prediction, GRN analysis, and zero-shot integration. The [`README.md`](https://github.com/bowang-lab/scgpt/pyproject.toml#L9) file within this directory provides a comprehensive guide to accessing these processed datasets, often linking to external resources.

For managing these datasets, [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) utilizes [`scBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L45), a structured data repository. This module facilitates the efficient import of [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, tokenization of gene expression data, management of metadata, and persistence of data to disk in the [`scb`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L49) format. The [`scBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L45) core components are defined within the [`/bowang-lab/scgpt/scgpt/scbank`](https://github.com/bowang-lab/scgpt/scgpt/scbank) directory.

The [`scBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L45) system is built around the [`DataBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L19) class, which acts as a central repository for multi-study single-cell data. It manages [`MetaInfo`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L43) (metadata), [`DataTable`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L11) objects, [`GeneVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L24) for gene tokenization, and [`Setting`](https://github.com/bowang-lab/scgpt/scgpt/scbank/setting.py#L7) objects for configuration. The [`DataBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L19) supports importing data directly from [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, tokenizing gene expression data, and persisting these processed data to disk. It handles [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) layers and observations, converting them into [`DataTable`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L11)s and ensuring token matching with the gene vocabulary. For large datasets, the [`DataBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L19) is designed to store data chunks on disk and load partitions into memory as needed, optimizing memory usage. It also automatically converts dense NumPy arrays to sparse [`csr_matrix`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L8) where appropriate to enhance memory and processing efficiency for typical biological data.
