#### Chunked Data Downloading and SLURM Parallelization
To manage the download of large datasets from the Cellxgene Census, [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) employs a strategy of chunked data downloading and parallel processing. This approach prevents memory overload and ensures efficient data retrieval.

The script [`/bowang-lab/scgpt/data/cellxgene/download_partition.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py) is central to this process. It downloads specific partitions of [`Homo sapiens`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py#L79) data from the Cellxgene Census, saving them as [`h5ad`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L14) files. The process involves identifying a list of SOMA IDs (unique Cellxgene Census identifiers) using [`load2list`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py#L60) and then selecting a subset of these IDs to form a manageable chunk using [`define_partition`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py#L50). This enables the retrieval of an [`anndata`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) object from the [`cellxgene_census`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L3), which is then saved to disk. A related function, [`del_partition`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py#L90), allows for the removal of previously downloaded partition files.

For parallel execution, especially in cluster environments, [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) utilizes SLURM array jobs through the script [`/bowang-lab/scgpt/data/cellxgene/array_download_partition.sh`](https://github.com/bowang-lab/scgpt/data/cellxgene/array_download_partition.sh). This shell script orchestrates the downloading of data partitions by defining SLURM parameters such as time, CPU, and memory allocation. It leverages the [`SLURM_ARRAY_TASK_ID`](https://github.com/bowang-lab/scgpt/data/cellxgene/array_build_scb.sh#L13) to iterate through a list of queries defined in [`QUERY_PATH`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L29), executing [`/bowang-lab/scgpt/data/cellxgene/download_partition.sh`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.sh) for each partition. This mechanism ensures that different parts of the dataset can be downloaded concurrently, significantly speeding up the overall data acquisition process.
