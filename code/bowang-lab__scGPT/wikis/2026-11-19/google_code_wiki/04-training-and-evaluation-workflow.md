#### Training and Evaluation Workflow
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) repository orchestrates the end-to-end process of training, evaluating, and applying single-cell GPT models, encompassing data preparation for diverse tasks, iterative training loops with various loss functions, validation on held-out sets, and comprehensive performance assessment.

The workflow begins with data preparation, managed by [`prepare_data`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L24) within [`/bowang-lab/scgpt/scgpt/trainer.py`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py). This function preprocesses tokenized gene expression data, applying masking strategies for denoising or prediction tasks. It structures the data into dictionaries suitable for both training and validation, accommodating different biological tasks such as cell type annotation, multi-batch integration, perturbation prediction, and multi-omic analysis. For optimal training efficiency, it can also sort sequences by batch, which is beneficial when utilizing specialized data samplers.

Data is then loaded using the [`SeqDataset`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L118) class and [`prepare_dataloader`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L130) function from [`/bowang-lab/scgpt/scgpt/trainer.py`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py). These components facilitate the creation of [`DataLoader`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L4) instances, which can either shuffle data conventionally or employ a custom batch sampling strategy. This strategy groups samples from the same "sequence batch" to ensure that each training batch contains related data, thereby potentially improving learning dynamics.

The core training process is executed by the [`train`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L173) function in [`/bowang-lab/scgpt/scgpt/trainer.py`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py). This function performs forward passes through the model and calculates various loss components. These components can include Gene Expression Prediction (GEP), Gene Expression Prediction with Cell Embeddings (GEPC), Cell-type Classification (CLS), Entropy-based Contrastive Learning (ECS), and Discriminative Adversarial Batch (DAR) losses. The integration of these diverse loss functions allows the model to learn from multiple aspects of single-cell data simultaneously. Model weights are updated using an optimizer and scheduler, and mixed-precision training is enabled through [`torch.cuda.amp.autocast`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L220) for enhanced performance and reduced memory footprint. Detailed training metrics are logged to [`wandb`](https://github.com/bowang-lab/scgpt/README.md#L40) for monitoring progress.

During training, model performance is regularly assessed on a validation set by the [`evaluate`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L379) function in [`/bowang-lab/scgpt/scgpt/trainer.py`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py). This function operates without weight updates, focusing solely on calculating the relevant loss for the specific task at hand (e.g., CLS loss for annotation tasks or GEP loss for integration tasks).

For comprehensive performance evaluation, particularly for classification tasks, the [`predict`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L463) and [`test`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L507) functions in [`/bowang-lab/scgpt/scgpt/trainer.py`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py) are utilized. [`predict`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L463) generates classification labels from input data, while [`test`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L507) processes raw [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, tokenizes them, and then uses [`predict`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L463) to derive predictions. It subsequently calculates and logs classification performance metrics such as accuracy, precision, recall, and F1-score.

A specialized evaluation function, [`eval_testdata`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L589) in [`/bowang-lab/scgpt/scgpt/trainer.py`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py), focuses on assessing the quality of cell embeddings. It uses the trained model to generate cell embeddings, stores them in the [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) object, and then leverages [`scib`](https://github.com/bowang-lab/scgpt/README.md#L99) metrics to quantify biological conservation and batch integration performance. This function also generates UMAP visualizations, offering a visual assessment of batch and cell-type integration, complementing the quantitative metrics. The various masked loss functions used during training are defined in [`/bowang-lab/scgpt/scgpt/loss.py`](https://github.com/bowang-lab/scgpt/scgpt/loss.py).
