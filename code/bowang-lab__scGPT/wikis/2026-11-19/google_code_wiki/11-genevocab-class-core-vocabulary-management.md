### GeneVocab Class: Core Vocabulary Management
The [`GeneVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L24) class, defined in [`/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py), is central to managing gene vocabularies within scGPT. It extends a base [`Vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L251) class, which is dynamically selected based on [`torchtext`](https://github.com/bowang-lab/scgpt/docs/environment.yml#L19) compatibility to ensure consistent functionality across different versions. See [Dynamic Vocab Compatibility and `torchtext` Adaptation](#gene-tokenization-and-vocabulary-dynamic-vocab-compatibility-and-torchtext-adaptation) for details on this dynamic compatibility.

[`GeneVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L24) can be initialized from various sources: a list of gene names, an existing [`Vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L251) object, or a [`torchtext`](https://github.com/bowang-lab/scgpt/docs/environment.yml#L19) vocabulary. This flexibility allows for diverse vocabulary construction scenarios. During initialization, it handles special tokens, such as padding tokens, and can set a default token for out-of-vocabulary terms. The class includes mechanisms for persistent storage and retrieval of vocabularies, offering [`from_file`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L113) methods to load from [`.pkl`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L120) or [`.json`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L223) files and [`save_json`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L221) to write vocabularies to JSON format. This enables efficient reuse of pre-built vocabularies without needing to reconstruct them every time.

A default gene vocabulary can be automatically built or retrieved using the [`get_default_gene_vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L242) function. This function attempts to load a default vocabulary from a predefined JSON file. If no such file exists, it constructs the vocabulary by fetching gene symbols and IDs from [`genenames.org`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L274) and then saves it for future use. This provides a standardized and readily available vocabulary for common use cases. The [`pad_token`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L201) property specifically manages the padding token, ensuring its presence within the vocabulary for proper batching operations.
