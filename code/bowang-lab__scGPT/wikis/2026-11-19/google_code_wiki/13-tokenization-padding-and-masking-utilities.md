### Tokenization, Padding, and Masking Utilities
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) project employs several utility functions to prepare gene expression data for transformer models, covering tokenization, padding, and masking, primarily defined within [`/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py).

Gene expression data, initially represented by numerical counts and gene identifiers, is converted into a tokenized format suitable for sequence models. The [`tokenize_batch`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L292) function performs this conversion by transforming non-zero gene expressions into a list of tuples, each containing a gene identifier and its corresponding expression count. Optionally, a [`cls_id`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L298) can be appended to these tokenized representations, serving as a special classification token.

Once tokenized, gene batches are uniformly sized through padding, which is handled by the [`pad_batch`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L355) function. This function extends shorter sequences to a [`max_len`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L525) using a specified [`pad_token`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L201) and [`pad_value`](https://github.com/bowang-lab/scgpt/scgpt/data_collator.py#L39). If a sequence exceeds [`max_len`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L525), genes are sampled to fit the target length, ensuring that the optional [`cls_appended`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L361) token remains at the beginning of the sequence. The [`tokenize_and_pad_batch`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L442) function combines these tokenization and padding steps into a single, streamlined process.

For tasks such as Masked Language Modeling (MLM), [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) incorporates a masking mechanism. The [`random_mask_value`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L485) function applies masking to a random subset of gene expression values within a batch. Based on a defined [`mask_ratio`](https://github.com/bowang-lab/scgpt/examples/finetune_integration.py#L89), selected values are replaced with a [`mask_value`](https://github.com/bowang-lab/scgpt/scgpt/data_collator.py#L43), while padding values are explicitly excluded from this process. This allows the model to learn to predict missing gene expressions based on context. For further details on the [`GeneVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L24) class which manages the underlying vocabulary, see [GeneVocab Class: Core Vocabulary Management](#gene-tokenization-and-vocabulary-genevocab-class-core-vocabulary-management).
