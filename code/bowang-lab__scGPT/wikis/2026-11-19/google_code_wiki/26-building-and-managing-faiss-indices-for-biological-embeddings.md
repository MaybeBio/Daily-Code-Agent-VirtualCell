### Building and Managing FAISS Indices for Biological Embeddings
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) project employs FAISS (Facebook AI Similarity Search) indices to facilitate efficient similarity searches on biological embedding data. This capability is particularly useful for tasks such as reference mapping and data integration in zero-shot applications. The primary mechanism for managing these indices is the [`FaissIndexBuilder`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L28) class, defined in [`/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py).

The [`FaissIndexBuilder`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L28) streamlines the process of creating, configuring, and storing FAISS indices. It is designed to ingest embedding data and associated metadata, typically from [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, which are a standard format in single-cell genomics. When initialized, the builder takes parameters defining input and output directories, embedding and metadata keys, and critical FAISS index specifications. It supports the acceleration of index operations using GPUs and allows for flexible index types through the [`faiss.index_factory`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L142) interface.

Data loading for index construction primarily involves reading [`.h5ad`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L55) files, where both embeddings (e.g., cell embeddings derived from [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) models) and metadata are often co-located. After loading, the builder constructs the FAISS index, training it with the provided embeddings. A key optimization is the automatic adjustment of the [`nprobe`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L145) parameter for [`faiss.IndexIVF`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L229) indices, which helps balance search speed and accuracy. Once built, the index, its metadata, and configuration details are persisted to disk, allowing for later retrieval and use.

Beyond index creation, the system provides utilities for loading existing FAISS indices and their corresponding metadata. It also includes functions for post-processing search results, such as [`compute_category_proportion`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L293) and [`weighted_vote`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L308), which can be used to aggregate and interpret similarity queries, especially when dealing with multiple similar matches. This robust framework for FAISS index management is central to enabling rapid and scalable similarity-based analyses within [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1)'s zero-shot capabilities. For more details on the practical applications, refer to [Zero-Shot Applications and Tutorials](#zero-shot-applications-and-tutorials).
