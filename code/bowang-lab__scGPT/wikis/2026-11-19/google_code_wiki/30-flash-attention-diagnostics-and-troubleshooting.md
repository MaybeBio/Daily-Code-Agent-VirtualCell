### Flash-Attention Diagnostics and Troubleshooting
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) repository includes utilities to diagnose and troubleshoot Flash-Attention (FA) usage. These tools are designed to verify which attention path (FA1, FA2, or PyTorch) is active, check the data type eligibility for FA2 kernels, measure peak CUDA memory consumption, and validate checkpoint key mappings. This functionality is primarily encapsulated within the [`/bowang-lab/scgpt/scripts`](https://github.com/bowang-lab/scgpt/scripts) directory.

The diagnostic script, [`/bowang-lab/scgpt/scripts/diagnose_flash_attn.py`](https://github.com/bowang-lab/scgpt/scripts/diagnose_flash_attn.py), assesses the interaction between [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1)'s [`FlashMHA`](https://github.com/bowang-lab/scgpt/scgpt/model/flash_attn_compat.py#L75) (Flash Multi-Head Attention) component and the [`flash-attn`](https://github.com/bowang-lab/scgpt/README.md#L18) library. It reports on the PyTorch, CUDA, and [`flash-attn`](https://github.com/bowang-lab/scgpt/README.md#L18) environment, including the detected [`flash_attn_backend`](https://github.com/bowang-lab/scgpt/scgpt/model/flash_attn_compat.py#L11). To perform its analysis, the script generates synthetic data and constructs a [`TransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L21), optionally loading a pre-trained checkpoint while handling parameter renaming rules necessary for [`FA1`](https://github.com/bowang-lab/scgpt/scripts/README.md#L8) to [`FA2`](https://github.com/bowang-lab/scgpt/scripts/README.md#L8) migration.

During a forward pass with this synthetic data, the script uses PyTorch's forward hooks to non-invasively inspect [`FlashMHA`](https://github.com/bowang-lab/scgpt/scgpt/model/flash_attn_compat.py#L75) modules. These hooks record critical runtime information, such as the [`FlashMHA`](https://github.com/bowang-lab/scgpt/scgpt/model/flash_attn_compat.py#L75) implementation type, whether [`use_flash_attn`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L333) is active, the input tensor's data type, and the status of [`autocast`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L220) enablement. This allows the script to identify potential performance bottlenecks or instances where the system might be falling back to slower PyTorch attention paths. After execution, the script analyzes the collected data to flag issues like [`use_flash_attn=False`](https://github.com/bowang-lab/scgpt/scripts/diagnose_flash_attn.py#L221) when FA2 is expected or incorrect [`float32`](https://github.com/bowang-lab/scgpt/scripts/README.md#L59) inputs during automatic mixed precision (AMP) operation. The overall process provides a summary and recommendations for optimizing [`flash-attn`](https://github.com/bowang-lab/scgpt/README.md#L18) usage within [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1). Further guidance on using and interpreting the output of this diagnostic tool is available in [`/bowang-lab/scgpt/scripts/README.md`](https://github.com/bowang-lab/scgpt/scripts/README.md).
