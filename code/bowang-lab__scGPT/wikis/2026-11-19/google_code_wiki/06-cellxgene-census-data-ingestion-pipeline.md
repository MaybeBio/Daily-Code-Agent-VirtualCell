### Cellxgene Census Data Ingestion Pipeline
The Cellxgene Census Data Ingestion Pipeline automates the construction of a pre-training cell corpus from the Cellxgene Census, designed to support large-scale machine learning model development. This pipeline is optimized for cluster environments leveraging SLURM for parallel processing. The process begins with configuring specific data queries, proceeds through indexing cell identifiers, downloading data in manageable chunks, converting the data into an efficient [`scb`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L49) format, and includes advanced filtering capabilities for specific cancer types and organs.

A core aspect of the pipeline is its configuration for data queries, primarily defined in [`/bowang-lab/scgpt/data/cellxgene/data_config.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py). This file establishes constants such as [`MAJOR_TISSUE_LIST`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L4), [`VERSION`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L5) for the Cellxgene Census, and the path to [`/bowang-lab/scgpt/data/cellxgene/cancer_list.txt`](https://github.com/bowang-lab/scgpt/data/cellxgene/cancer_list.txt), which enumerates cancer types. These definitions are used to construct SQL-like filter strings in [`VALUE_FILTER`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L12) for querying normal tissue samples, "other" tissues not explicitly listed, and pan-cancer datasets based on disease types. The [`/bowang-lab/scgpt/data/cellxgene/query_list.txt`](https://github.com/bowang-lab/scgpt/data/cellxgene/query_list.txt) file further specifies human organs and conditions for targeting data retrieval.

Once queries are defined, the pipeline indexes cell identifiers. The [`soma_joinid`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L37)s, which are unique Cellxgene Census identifiers, are retrieved based on the specified queries. This is managed by [`/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py), which uses [`retrieve_soma_idx`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L29) to query the census and [`convert2file`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L43) to save these identifiers into [`.idx`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L51) files. The shell script [`/bowang-lab/scgpt/data/cellxgene/build_soma_idx.sh`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.sh) orchestrates this indexing for multiple queries. For further details on this process, see [Cell Indexing and Query Definition](#data-management-and-preprocessing-cellxgene-census-data-ingestion-pipeline-cell-indexing-and-query-definition).

For efficient handling of large datasets, the pipeline employs a chunked data downloading strategy. [`/bowang-lab/scgpt/data/cellxgene/download_partition.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py) facilitates downloading specific partitions of Homo sapiens data from the Cellxgene Census as [`h5ad`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L14) files. It leverages [`load2list`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py#L60) to read SOMA IDs, [`define_partition`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py#L50) to select a subset of IDs, and [`download_partition`](https://github.com/bowang-lab/scgpt/data/cellxgene/download_partition.py#L70) to execute the query and save the [`anndata`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) object. The [`/bowang-lab/scgpt/data/cellxgene/array_download_partition.sh`](https://github.com/bowang-lab/scgpt/data/cellxgene/array_download_partition.sh) script utilizes SLURM array jobs to parallelize these chunked downloads, ensuring efficient retrieval of vast quantities of data. More information can be found in [Chunked Data Downloading and SLURM Parallelization](#data-management-and-preprocessing-cellxgene-census-data-ingestion-pipeline-chunked-data-downloading-and-slurm-parallelization).

Following the download, the [`h5ad`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L14) files are converted into the [`scb`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L49) (single-cell bank) format, which is optimized for high-performance I/O in downstream machine learning tasks. This conversion is handled by [`/bowang-lab/scgpt/data/cellxgene/build_large_scale_data.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_large_scale_data.py), which preprocesses [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, filtering cells and genes as needed, and then converts them into [`scbank.DataBank`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_large_scale_data.py#L190) objects. The [`/bowang-lab/scgpt/data/cellxgene/array_build_scb.sh`](https://github.com/bowang-lab/scgpt/data/cellxgene/array_build_scb.sh) script orchestrates this conversion process across multiple datasets using SLURM array jobs.

The pipeline also includes mechanisms for gene vocabulary expansion and data processing for model training. [`/bowang-lab/scgpt/data/cellxgene/expand_gene_list.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/expand_gene_list.py) updates the gene vocabulary by incorporating new gene symbols from the Cellxgene Census. Finally, [`/bowang-lab/scgpt/data/cellxgene/process_allcounts.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/process_allcounts.py) configures and preprocesses single-cell gene expression data for transformer model training, loading vocabularies and appending special tokens like [`"<cls>"`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L529). This comprehensive approach ensures that vast amounts of single-cell data are efficiently prepared for advanced analysis and model training.
