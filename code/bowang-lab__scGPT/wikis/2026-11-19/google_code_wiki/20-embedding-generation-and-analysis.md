## Embedding Generation and Analysis
scGPT provides functionalities for generating, analyzing, and visualizing gene and cell embeddings from single-cell RNA-seq data, leveraging transformer models and [`scanpy`](https://github.com/bowang-lab/scgpt/README.md#L97) for downstream analyses. The primary components for these tasks are exposed through [`/bowang-lab/scgpt/scgpt/tasks`](https://github.com/bowang-lab/scgpt/scgpt/tasks).

Cell embeddings are generated from single-cell RNA-seq data using a pre-trained [`TransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L21). The [`embed_data`](https://github.com/bowang-lab/scgpt/scgpt/tasks/cell_emb.py#L148) function within [`/bowang-lab/scgpt/scgpt/tasks/cell_emb.py`](https://github.com/bowang-lab/scgpt/scgpt/tasks/cell_emb.py) orchestrates this process, loading a model and its associated vocabulary, preprocessing [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects to match genes with the model's vocabulary, and then computing embeddings. The [`get_batch_cell_embeddings`](https://github.com/bowang-lab/scgpt/scgpt/tasks/cell_emb.py#L22) function handles the batch processing of [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, transforming gene expression profiles into dense, numerical representations. These embeddings, typically derived from the model's [`<cls>`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L529) token output, can be used for various downstream analyses.

For gene embeddings, the [`GeneEmbedding`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py#L18) class, defined in [`/bowang-lab/scgpt/scgpt/tasks/grn.py`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py), manages gene embeddings and provides tools for their analysis and visualization. It initializes with gene names and their corresponding embedding vectors, which can be loaded from files. The system can convert these gene embeddings into a [`scanpy`](https://github.com/bowang-lab/scgpt/README.md#L97) [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) object, allowing for standard analyses such as neighborhood graph construction, Leiden clustering, and UMAP dimensionality reduction. This enables the visualization of gene clusters, referred to as metagenes. Furthermore, [`GeneEmbedding`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py#L18) facilitates the computation and plotting of gene similarities using cosine similarity, the scoring of metagenes within [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, and the construction of gene similarity networks using [`networkx`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py#L7). These tools support the investigation of gene relationships and the impact of specific gene sets.
