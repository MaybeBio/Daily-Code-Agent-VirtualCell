## Model Architectures and Training
scGPT employs transformer-based models designed to process single-cell and multi-omic gene expression data, supporting a range of functionalities from data encoding to various prediction and integration tasks. The primary implementations reside in the [`/bowang-lab/scgpt/scgpt/model`](https://github.com/bowang-lab/scgpt/scgpt/model) directory.

The system utilizes specialized encoders, such as [`GeneEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L717), [`ContinuousValueEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L759), [`CategoryValueEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L789), and [`BatchLabelEncoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L809), to convert raw gene identifiers, continuous expression values, categorical values, and batch labels into dense embeddings suitable for transformer input. These embeddings are then processed by a transformer encoder, which can be configured to use standard PyTorch implementations or optimized attention mechanisms for computational efficiency, such as those provided by [`FlashTransformerEncoderLayer`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L588) and [`FastTransformerEncoderWrapper`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L500). For details on the dynamic compatibility with [`flash-attn`](https://github.com/bowang-lab/scgpt/README.md#L18) backends, see [Optimized Attention Mechanisms](#model-architectures-and-training-optimized-attention-mechanisms).

The core model, [`TransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L21) in [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), supports various training objectives:
*   **Masked Gene Modeling:** Predicts masked gene expression values using an [`ExprDecoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L842).
*   **Cell-Type Classification:** Classifies cell types based on cell embeddings via a [`ClsDecoder`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L884).
*   **Contrastive Learning:** Uses objectives like Contrastive Cell Embedding (CCE) and Elastic Cell Similarity (ECS) to learn robust cell representations by maximizing agreement between related embeddings.
*   **Adversarial Domain Adaptation:** Integrates an [`AdversarialDiscriminator`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L1007) with a [`grad_reverse`](https://github.com/bowang-lab/scgpt/scgpt/model/grad_reverse.py#L16) mechanism to mitigate batch effects and learn domain-invariant features. This process helps ensure that cell embeddings are comparable across different experimental batches or datasets. The [`DomainSpecificBatchNorm1d`](https://github.com/bowang-lab/scgpt/scgpt/model/dsbn.py#L63) module in [`/bowang-lab/scgpt/scgpt/model/dsbn.py`](https://github.com/bowang-lab/scgpt/scgpt/model/dsbn.py) further assists in batch effect correction by maintaining separate batch normalization statistics for different domains.

For multi-omic datasets, the [`MultiOmicTransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/multiomic_model.py#L21) in [`/bowang-lab/scgpt/scgpt/model/multiomic_model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/multiomic_model.py) extends these capabilities, enabling the integration and analysis of diverse data types. It shares many architectural components with the [`TransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L21), adapting them for multi-omic input and tasks.

The [`TransformerGenerator`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py#L27) in [`/bowang-lab/scgpt/scgpt/model/generation_model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py) is specifically designed for generative tasks, including masked gene modeling and perturbation prediction. It incorporates a [`pert_encoder`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py#L80) to embed perturbation flags and utilizes an [`AffineExprDecoder`](https://github.com/bowang-lab/scgpt/scgpt/model/generation_model.py#L373) to predict both baseline gene expression and the effects of perturbations.

Model training involves feeding these encoded inputs through the transformer, computing task-specific losses (e.g., MLM loss, classification loss, adversarial loss), and optimizing the model parameters. Evaluation often includes metrics from [`scib`](https://github.com/bowang-lab/scgpt/README.md#L99) and visualization techniques like UMAP to assess the quality of cell embeddings and batch correction. For a deeper understanding of the loss functions, refer to [Training and Evaluation Workflow](#introduction-to-scgpt-scgpt-package-structure-and-core-modules-training-and-evaluation-workflow).
