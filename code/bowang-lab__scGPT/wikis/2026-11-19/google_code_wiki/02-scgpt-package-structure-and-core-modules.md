### scGPT Package Structure and Core Modules
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) package is organized to facilitate single-cell multi-omics analysis through generative AI. Its primary components are exposed via [`/bowang-lab/scgpt/scgpt/__init__.py`](https://github.com/bowang-lab/scgpt/scgpt/__init__.py), providing access to core functionalities for data management, model training, evaluation, and analysis.

The package integrates modules for various stages of the workflow:
*   **Model Architectures**: The [`model`](https://github.com/bowang-lab/scgpt/examples/finetune_integration.py#L385) module in [`/bowang-lab/scgpt/scgpt/model`](https://github.com/bowang-lab/scgpt/scgpt/model) houses the transformer-based models designed for single-cell and multi-omic gene expression data. These architectures support functionalities like gene encoding, value encoding, masked gene modeling, cell-type classification, perturbation prediction, contrastive learning, and adversarial domain adaptation. For more details, refer to [Model Architectures and Training](#model-architectures-and-training).
*   **Tokenization**: The [`tokenizer`](https://github.com/bowang-lab/scgpt/pyproject.toml#L61) module in [`/bowang-lab/scgpt/scgpt/tokenizer`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer) is responsible for creating, loading, and managing gene vocabularies. It handles the tokenization and padding of gene expression data and adapts to different [`torchtext`](https://github.com/bowang-lab/scgpt/docs/environment.yml#L19) [`Vocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/vocab_compat.py#L251) API versions. Additional information can be found in [Gene Tokenization and Vocabulary](#gene-tokenization-and-vocabulary).
*   **Data Banking**: The [`scbank`](https://github.com/bowang-lab/scgpt/docs/scgpt.rst#L11) module in [`/bowang-lab/scgpt/scgpt/scbank`](https://github.com/bowang-lab/scgpt/scgpt/scbank) serves as a structured repository for managing large-scale single-cell RNA-seq datasets, including handling [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, gene tokenization, and metadata management. See [scBank: Structured Data Repository and AnnData Handling](#data-management-and-preprocessing-scbank-structured-data-repository-and-anndata-handling) for further information.
*   **General Utilities**: The [`utils`](https://github.com/bowang-lab/scgpt/README.md#L18) module in [`/bowang-lab/scgpt/scgpt/utils`](https://github.com/bowang-lab/scgpt/scgpt/utils) provides a collection of utility functions for environment setup, logging, data processing, visualization, model evaluation, and distributed training. Further details are in [Utility Functions and Diagnostics](#utility-functions-and-diagnostics).
*   **Task-Specific Modules**: The [`tasks`](https://github.com/bowang-lab/scgpt/README.md#L16) module in [`/bowang-lab/scgpt/scgpt/tasks`](https://github.com/bowang-lab/scgpt/scgpt/tasks) provides tools for generating, analyzing, and visualizing gene and cell embeddings from single-cell RNA-seq data, leveraging transformer models and [`scanpy`](https://github.com/bowang-lab/scgpt/README.md#L97) for downstream analyses. Refer to [Embedding Generation and Analysis](#embedding-generation-and-analysis) for more information.

Beyond these modules, the package exposes several key classes and functions directly from [`/bowang-lab/scgpt/scgpt/__init__.py`](https://github.com/bowang-lab/scgpt/scgpt/__init__.py):
*   [`DataCollator`](https://github.com/bowang-lab/scgpt/scgpt/data_collator.py#L11) in [`/bowang-lab/scgpt/scgpt/data_collator.py`](https://github.com/bowang-lab/scgpt/scgpt/data_collator.py) is used for batching and preprocessing data for mask value learning tasks, handling padding, truncation, binning, and masking of gene and expression values.
*   [`SubsetsBatchSampler`](https://github.com/bowang-lab/scgpt/scgpt/data_sampler.py#L25) in [`/bowang-lab/scgpt/scgpt/data_sampler.py`](https://github.com/bowang-lab/scgpt/scgpt/data_sampler.py) provides custom PyTorch [`Sampler`](https://github.com/bowang-lab/scgpt/scgpt/data_sampler.py#L5) implementations for flexible data batching, enabling sampling from multiple distinct data subsets with configurable shuffling.
*   Functions related to the training and evaluation workflow, such as [`prepare_data`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L24), [`prepare_dataloader`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L130), [`train`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L173), [`evaluate`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L379), [`test`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L507), [`define_wandb_metrcis`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L372), and [`eval_testdata`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L589) from [`/bowang-lab/scgpt/scgpt/trainer.py`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py), orchestrate the entire learning pipeline, from data preparation to performance metric computation.

The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) package also handles data preprocessing via the [`Preprocessor`](https://github.com/bowang-lab/scgpt/scgpt/preprocess.py#L13) class in [`/bowang-lab/scgpt/scgpt/preprocess.py`](https://github.com/bowang-lab/scgpt/scgpt/preprocess.py), which transforms raw single-cell RNA sequencing data into a format suitable for various models. Masked loss functions are defined in [`/bowang-lab/scgpt/scgpt/loss.py`](https://github.com/bowang-lab/scgpt/scgpt/loss.py) to compare model outputs with targets, ignoring specific elements based on a mask.
