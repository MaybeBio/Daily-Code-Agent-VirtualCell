#### Cell Indexing and Query Definition
The process of defining queries and indexing [`soma_joinid`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L37)s from the Cellxgene Census begins with the configuration of data queries. This involves setting up constants such as [`MAJOR_TISSUE_LIST`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L4), [`VERSION`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L5), and [`CANCER_LIST_PATH`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L7) within [`/bowang-lab/scgpt/data/cellxgene/data_config.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py). This file programmatically constructs SQL-like filter strings stored in [`VALUE_FILTER`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L12) for querying normal tissue samples, specific "other" tissues, and [`pan-cancer`](https://github.com/bowang-lab/scgpt/README.md#L69) datasets based on disease lists. The [`CANCER_LIST_PATH`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L7) points to [`/bowang-lab/scgpt/data/cellxgene/cancer_list.txt`](https://github.com/bowang-lab/scgpt/data/cellxgene/cancer_list.txt), which enumerates various cancer types used to build the [`pan-cancer`](https://github.com/bowang-lab/scgpt/README.md#L69) filter. [`/bowang-lab/scgpt/data/cellxgene/query_list.txt`](https://github.com/bowang-lab/scgpt/data/cellxgene/query_list.txt) further specifies predefined human organs and conditions for querying.

Once queries are defined, the system proceeds to cell indexing. The script [`/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py) is responsible for retrieving [`soma_joinid`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L37)s (unique Cellxgene Census identifiers). It queries the Cellxgene Census using [`cellxgene_census.open_soma`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L34) and the [`VALUE_FILTER`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py#L12) from [`/bowang-lab/scgpt/data/cellxgene/data_config.py`](https://github.com/bowang-lab/scgpt/data/cellxgene/data_config.py). These identifiers are then saved to [`.idx`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.py#L51) files for efficient data access, with the process orchestrated by [`/bowang-lab/scgpt/data/cellxgene/build_soma_idx.sh`](https://github.com/bowang-lab/scgpt/data/cellxgene/build_soma_idx.sh). This step ensures that specific cell populations can be precisely identified and retrieved for subsequent data processing.
