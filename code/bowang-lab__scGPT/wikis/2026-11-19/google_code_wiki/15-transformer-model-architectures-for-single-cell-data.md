### Transformer Model Architectures for Single-Cell Data
scGPT utilizes transformer-based architectures to process single-cell and multi-omic gene expression data. The primary models, [`TransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L21) and [`MultiOmicTransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/multiomic_model.py#L21), are designed to integrate gene, value, and batch information to support various analytical tasks.

The [`TransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L21), defined in [`/bowang-lab/scgpt/scgpt/model/model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py), processes single-cell gene expression data by first encoding gene identifiers, continuous expression values, and optional batch labels into a combined embedding space. These embeddings are then fed into a Transformer encoder, which can be configured to use standard, fast, or [`FlashTransformerEncoderLayer`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L588) attention mechanisms for optimized computational efficiency. The model supports multiple objectives including Masked Language Modeling (MLM) for predicting gene expression, cell-type classification (CLS), Contrastive Cell Embedding (CCE) for self-supervised learning, and adversarial domain adaptation (DAB) to correct for batch effects.

For datasets comprising multiple omics layers, the [`MultiOmicTransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/multiomic_model.py#L21), located in [`/bowang-lab/scgpt/scgpt/model/multiomic_model.py`](https://github.com/bowang-lab/scgpt/scgpt/model/multiomic_model.py), extends this architecture. It similarly encodes gene, value, and batch information, alongside modality types, and processes them through a Transformer encoder. This model supports the same diverse range of tasks as the [`TransformerModel`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L21), including MLM, CLS, CCE, and DAB, ensuring its applicability across complex multi-omic data. Both models utilize [`DomainSpecificBatchNorm1d`](https://github.com/bowang-lab/scgpt/scgpt/model/dsbn.py#L63) from [`/bowang-lab/scgpt/scgpt/model/dsbn.py`](https://github.com/bowang-lab/scgpt/scgpt/model/dsbn.py) and a [`grad_reverse`](https://github.com/bowang-lab/scgpt/scgpt/model/grad_reverse.py#L16) layer from [`/bowang-lab/scgpt/scgpt/model/grad_reverse.py`](https://github.com/bowang-lab/scgpt/scgpt/model/grad_reverse.py) to facilitate adversarial training for batch effect correction.

To enhance computational efficiency, both models integrate optimized attention mechanisms. This includes [`FlashTransformerEncoderLayer`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L588) and [`FastTransformerEncoderWrapper`](https://github.com/bowang-lab/scgpt/scgpt/model/model.py#L500), which utilize high-performance Flash attention backends or linear attention techniques. Compatibility with different versions of the [`flash-attn`](https://github.com/bowang-lab/scgpt/README.md#L18) library is managed through [`/bowang-lab/scgpt/scgpt/model/flash_attn_compat.py`](https://github.com/bowang-lab/scgpt/scgpt/model/flash_attn_compat.py), which provides a unified interface and handles dynamic loading of available backends. For a detailed explanation of Flash-Attention diagnostics, see [Flash-Attention Diagnostics and Troubleshooting](#utility-functions-and-diagnostics-flash-attention-diagnostics-and-troubleshooting).

The overall structure of these models, including their various encoders, decoders, and specialized layers, is aggregated and exposed through [`/bowang-lab/scgpt/scgpt/model/__init__.py`](https://github.com/bowang-lab/scgpt/scgpt/model/__init__.py), streamlining their integration into broader workflows within the scGPT framework.
