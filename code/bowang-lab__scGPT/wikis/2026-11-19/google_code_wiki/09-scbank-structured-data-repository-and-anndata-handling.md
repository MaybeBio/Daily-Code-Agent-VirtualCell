### scBank: Structured Data Repository and AnnData Handling
The [`scBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L45) module provides a structured repository for managing large-scale single-cell RNA-seq datasets, designed to streamline data handling from import to persistence. The core of this system is the [`DataBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L19) class, which serves as a central hub for organizing multi-study single-cell data. It manages metadata, stores data tables, handles gene tokenization, and applies configuration settings.

Data within [`scBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L45) is represented using [`DataTable`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L11) objects, which encapsulate individual data tables with names and associated [`Dataset`](https://github.com/bowang-lab/scgpt/scgpt/tasks/cell_emb.py#L64) objects. Metadata for an entire [`scBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L45) data directory is managed by the [`MetaInfo`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L43) class, tracking essential information such as on-disk path, data format, main data table key, and gene vocabulary checksum. This structured approach facilitates efficient data access and management.

A key capability of [`scBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L45) is its integration with [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, a common format in single-cell genomics. The [`DataBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L19) can import data directly from [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects or their file paths, tokenizing gene expression data as part of this process. This tokenization is critical for downstream machine learning tasks, as it converts gene names into numerical identifiers using a [`GeneVocab`](https://github.com/bowang-lab/scgpt/scgpt/tokenizer/gene_tokenizer.py#L24) object. For large datasets, the system can tokenize data from specific layers or observations within an [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) object, ensuring efficient memory usage.

[`scBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L45) is also designed for data persistence and synchronization. Changes to the [`DataBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L19) can be tracked and then synchronized to disk, saving metadata, data tables (typically in [`scb`](https://github.com/bowang-lab/scgpt/data/cellxgene/README.md#L49) format), and the gene vocabulary. While a full [`save`](https://github.com/bowang-lab/scgpt/scgpt/scbank/data.py#L23) mechanism is planned for future development, the current [`sync`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L634) functionality supports managing data on disk. Configuration settings, defined by the [`Setting`](https://github.com/bowang-lab/scgpt/scgpt/scbank/setting.py#L7) dataclass in [`/bowang-lab/scgpt/scgpt/scbank/setting.py`](https://github.com/bowang-lab/scgpt/scgpt/scbank/setting.py), allow customization of [`DataBank`](https://github.com/bowang-lab/scgpt/scgpt/scbank/databank.py#L19) behavior, such as removing zero rows during data loading or controlling immediate saving to disk. The overall design emphasizes managing large datasets by storing data chunks on disk and providing mechanisms to load relevant partitions as needed, as indicated by placeholder methods for large-scale data handling.
