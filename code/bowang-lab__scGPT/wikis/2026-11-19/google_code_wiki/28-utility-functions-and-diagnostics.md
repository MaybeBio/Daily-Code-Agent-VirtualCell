## Utility Functions and Diagnostics
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) repository includes a suite of utility functions and diagnostic tools to support single-cell genomics workflows, covering aspects from environment setup and data processing to model evaluation and distributed training. These utilities are primarily located within the [`/bowang-lab/scgpt/scgpt/utils`](https://github.com/bowang-lab/scgpt/scgpt/utils) directory.

Core utilities facilitate reproducibility through functions that set random seeds for [`random`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L49), [`numpy`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L7), and [`torch`](https://github.com/bowang-lab/scgpt/README.md#L18), and manage logging to files. Functions such as [`get_free_gpu`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L76) assist in dynamically identifying available GPU resources. For data processing, there are mechanisms to convert categorical strings to integer IDs, map raw gene IDs to a predefined vocabulary, and efficiently manage [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) object column names for consistency. Model-specific utilities include [`load_pretrained`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L309) for loading weights, which also handles parameter renaming to ensure compatibility across different model architectures or versions, particularly for optimized attention mechanisms. Evaluation metrics for single-cell integration are provided by [`eval_scib_metrics`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L394), which computes [`scib`](https://github.com/bowang-lab/scgpt/README.md#L99) metrics like [`silhouette_`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L409), [`graph_conn_`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L411), and [`nmi_`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L415), while [`compute_perturbation_metrics`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L452) calculates performance for perturbation predictions. For distributed training, decorators like [`main_process_only`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L622) ensure that specific functions run only on the main process.

A specialized set of tools for diagnosing and troubleshooting Flash-Attention usage within [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) is located in the [`/bowang-lab/scgpt/scripts`](https://github.com/bowang-lab/scgpt/scripts) directory. The [`diagnose_flash_attn.py`](https://github.com/bowang-lab/scgpt/scripts/README.md#L5) script helps verify which Flash-Attention backend (FA1, FA2, or standard PyTorch) is active, checks the eligibility of data types (e.g., [`fp16`](https://github.com/bowang-lab/scgpt/scripts/README.md#L9)/[`bf16`](https://github.com/bowang-lab/scgpt/scripts/README.md#L9)) for FA2 kernels, measures peak CUDA memory consumption, and validates checkpoint key mappings to ensure seamless model loading. This diagnostic script generates synthetic data and uses PyTorch's forward hooks to non-invasively inspect the behavior of [`FlashMHA`](https://github.com/bowang-lab/scgpt/scgpt/model/flash_attn_compat.py#L75) modules during a forward pass. It reports on environmental details, model configuration, and provides insights into potential issues like unexpected [`float32`](https://github.com/bowang-lab/scgpt/scripts/README.md#L59) inputs when Automatic Mixed Precision (AMP) is enabled. This helps optimize the computational efficiency of [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1)'s transformer models by ensuring Flash-Attention is correctly configured and utilized.
