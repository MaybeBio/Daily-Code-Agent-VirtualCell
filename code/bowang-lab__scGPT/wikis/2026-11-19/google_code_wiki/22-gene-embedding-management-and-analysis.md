### Gene Embedding Management and Analysis
The [`GeneEmbedding`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py#L18) class, located in [`/bowang-lab/scgpt/scgpt/tasks/grn.py`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py) and exposed through [`/bowang-lab/scgpt/scgpt/tasks/__init__.py`](https://github.com/bowang-lab/scgpt/scgpt/tasks/__init__.py), provides functionalities for managing, analyzing, and visualizing gene embeddings. Gene embeddings are numerical vector representations of genes, which allow for quantitative comparison and analysis of gene relationships.

The class can be initialized by mapping gene names to their corresponding embedding vectors, which are then stored internally. These embeddings can be loaded from files using a static method that parses a specified file format.

A key capability of [`GeneEmbedding`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py#L18) is its integration with [`scanpy`](https://github.com/bowang-lab/scgpt/README.md#L97) for comprehensive single-cell data analysis. It can convert gene embeddings into an [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) object, enabling standard [`scanpy`](https://github.com/bowang-lab/scgpt/README.md#L97) workflows such as computing neighbors, performing Leiden clustering to identify gene groups or metagenes, and generating UMAP visualizations for dimensionality reduction. This allows for visual exploration of gene relationships in a lower-dimensional space.

Beyond basic management, the [`GeneEmbedding`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py#L18) class facilitates advanced analysis of gene similarities. It computes cosine similarity between gene embedding vectors to quantify their relatedness. This can be used to find genes most similar to a target gene or to construct a gene similarity network using [`networkx`](https://github.com/bowang-lab/scgpt/scgpt/tasks/grn.py#L7). The class also supports the generation of metagenes by clustering gene embeddings and provides methods to score these metagenes across different cell populations or conditions, which can then be visualized using clustered heatmaps. Furthermore, it can compute weighted or unweighted average embedding vectors for a list of genes, which can represent functional gene sets. The analysis and generation of cell embeddings are handled by related components. See [Cell Embedding Generation and Preprocessing](#embedding-generation-and-analysis-cell-embedding-generation-and-preprocessing) for more details.
