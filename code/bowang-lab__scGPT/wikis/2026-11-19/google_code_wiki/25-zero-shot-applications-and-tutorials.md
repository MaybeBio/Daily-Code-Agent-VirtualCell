## Zero-Shot Applications and Tutorials
[`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1)'s zero-shot capabilities allow for the application of pretrained models to new datasets without requiring additional training, focusing on tasks such as reference mapping and data integration. These functionalities are explored within the tutorials provided in the [`/bowang-lab/scgpt/tutorials`](https://github.com/bowang-lab/scgpt/tutorials) directory.

A key component enabling efficient similarity search for zero-shot applications is the use of FAISS (Facebook AI Similarity Search) indices, which are managed through the [`FaissIndexBuilder`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py#L28) class defined in [`/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py`](https://github.com/bowang-lab/scgpt/tutorials/build_atlas_index_faiss.py). This class facilitates the building, saving, and loading of FAISS indices from biological embedding data, which is crucial for quickly identifying similar cells or genes across diverse datasets. The builder supports various FAISS index types and can leverage GPU acceleration for faster processing. Embeddings and associated metadata are typically loaded from [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, allowing for integration with common single-cell analysis workflows.

The challenges associated with technical batch effects, which can arise from variations in experimental protocols, are addressed through continually pretrained models. The [`scGPT_CP`](https://github.com/bowang-lab/scgpt/tutorials/zero-shot/README.md#L18) model, for instance, is a continually pretrained version of [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) that has been supervised with cell type labels from the [`Tabula Sapiens`](https://github.com/bowang-lab/scgpt/data/cellxgene/metainfo.json#L52) dataset. This approach helps [`scGPT_CP`](https://github.com/bowang-lab/scgpt/tutorials/zero-shot/README.md#L18) to inherently account for cell types and technical batch effects, improving zero-shot performance and data integration across heterogeneous datasets. Further details on how [`scGPT_CP`](https://github.com/bowang-lab/scgpt/tutorials/zero-shot/README.md#L18) mitigates these effects are discussed in [Addressing Technical Batch Effects with Continual Pretraining](#zero-shot-applications-and-tutorials-addressing-technical-batch-effects-with-continual-pretraining). The design philosophy behind this is to maintain an unbiased, data-driven pre-training approach while allowing flexibility for fine-tuning based on specific analytical goals.
