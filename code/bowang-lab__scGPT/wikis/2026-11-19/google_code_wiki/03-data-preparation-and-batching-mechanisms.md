#### Data Preparation and Batching Mechanisms
The data preparation and batching mechanisms within [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) are designed to transform raw single-cell RNA sequencing data into a format suitable for transformer-based models, facilitating tasks such as Masked Language Modeling (MLM). This process involves a series of steps, from initial preprocessing to custom batch sampling and data collation.

Data preprocessing is handled by the [`Preprocessor`](https://github.com/bowang-lab/scgpt/scgpt/preprocess.py#L13) class in [`/bowang-lab/scgpt/scgpt/preprocess.py`](https://github.com/bowang-lab/scgpt/scgpt/preprocess.py). This class orchestrates common steps for [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, including filtering genes and cells based on expression counts, normalizing total counts, applying [`log1p`](https://github.com/bowang-lab/scgpt/scgpt/preprocess.py#L26) transformation, selecting highly variable genes, and binning continuous expression values. Binning converts continuous data into discrete categories, which can be useful for tokenization in models that expect discrete inputs. The [`Preprocessor`](https://github.com/bowang-lab/scgpt/scgpt/preprocess.py#L13) ensures that data is consistently formatted and cleaned before further processing.

Following preprocessing, the [`DataCollator`](https://github.com/bowang-lab/scgpt/scgpt/data_collator.py#L11) in [`/bowang-lab/scgpt/scgpt/data_collator.py`](https://github.com/bowang-lab/scgpt/scgpt/data_collator.py) plays a central role in preparing batches for model input, particularly for tasks like MLM. This component manages padding and truncation of gene and expression sequences to uniform lengths, ensuring compatibility with fixed-size model inputs. For MLM tasks, it intelligently masks a percentage of expression values, replacing them with a designated [`mask_value`](https://github.com/bowang-lab/scgpt/scgpt/data_collator.py#L43), which enables the model to learn context by predicting these masked values. The [`DataCollator`](https://github.com/bowang-lab/scgpt/scgpt/data_collator.py#L11) also supports binning expressions if configured, further discretizing values. It ensures that special tokens, typically located at the beginning of a sequence, are preserved from masking or sampling.

For flexible data loading and training, [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) employs custom batch sampling strategies defined in [`/bowang-lab/scgpt/scgpt/data_sampler.py`](https://github.com/bowang-lab/scgpt/scgpt/data_sampler.py). The [`SubsetsBatchSampler`](https://github.com/bowang-lab/scgpt/scgpt/data_sampler.py#L25) allows for the creation of batches from multiple distinct subsets of data indices. This is particularly useful in scenarios where a dataset might be partitioned (e.g., by cell type or experimental batch) and there's a need to sample batches either sequentially or randomly from these partitions. It supports both intra-subset shuffling (shuffling indices within each partition) and inter-subset shuffling (randomizing the order in which batches are drawn from different partitions), providing fine-grained control over the batching process to optimize training dynamics.
