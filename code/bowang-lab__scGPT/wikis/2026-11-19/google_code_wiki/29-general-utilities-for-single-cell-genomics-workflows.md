### General Utilities for Single-Cell Genomics Workflows
The [`scGPT`](https://github.com/bowang-lab/scgpt/README.md#L1) repository includes a collection of general utility functions in [`/bowang-lab/scgpt/scgpt/utils/util.py`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py) designed to streamline various aspects of single-cell genomics workflows. These utilities cover environment setup, logging, data processing, visualization, model evaluation, and distributed training.

For environment setup, a [`set_seed`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L29) function is available to ensure reproducibility across random number generators in [`random`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L49), [`numpy`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L7), and [`torch`](https://github.com/bowang-lab/scgpt/README.md#L18). To facilitate debugging and record operational details, [`add_file_handler`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L40) allows logging messages to a specified file. The [`isnotebook`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L62) function detects if the execution environment is a Jupyter or IPython notebook, which can be useful for conditional behaviors like rendering plots. System utilities also include [`get_free_gpu`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L76) for identifying available GPUs based on memory usage, and functions like [`get_git_commit`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L102) and [`get_git_diff`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L106) to retrieve version control information.

In terms of data processing, utilities are provided for managing gene vocabularies and preparing data for model input. [`category_str2int`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L56) converts string categories into integer IDs, while [`find_required_colums`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L192) interactively identifies and persistently stores essential column names (e.g., cell type, gene name, batch key) for [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) objects, saving configurations to JSON for future use. For handling tensor data, [`tensorlist2tensor`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L263) pads and converts lists of tensors into a single tensor, and [`map_raw_id_to_vocab_id`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L274) maps raw gene identifiers to vocabulary-specific IDs.

Model-related utilities include [`load_pretrained`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L309), which facilitates loading pretrained weights into a [`torch.nn.Module`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L310). This function incorporates logic to adapt to different attention implementations, such as Flash Attention, by renaming parameter keys to ensure compatibility.

For model evaluation, [`eval_scib_metrics`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L394) computes a suite of single-cell integration benchmark ([`scib`](https://github.com/bowang-lab/scgpt/README.md#L99)) metrics, including silhouette and graph connectivity, on [`AnnData`](https://github.com/bowang-lab/scgpt/scgpt/trainer.py#L9) latent embeddings. Additionally, [`compute_perturbation_metrics`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L452) calculates performance metrics for perturbation prediction models, such as Pearson correlations of gene expression changes, distinguishing between all genes and differentially expressed genes.

Finally, for distributed training, [`main_process_only`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L622) and [`MainProcessOnly`](https://github.com/bowang-lab/scgpt/scgpt/utils/util.py#L632) are provided to ensure that specific functions or methods run exclusively on the main process, preventing redundant operations in multi-GPU or multi-node setups.
