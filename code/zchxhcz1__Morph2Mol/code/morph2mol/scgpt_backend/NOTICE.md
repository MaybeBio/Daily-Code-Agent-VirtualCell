# scGPT components

The RNA embedding model, data collator and expression binning are adapted from
[scGPT](https://github.com/bowang-lab/scGPT) (0.2.4), under the [MIT license](https://github.com/zchxhcz1/Morph2Mol/blob/HEAD/morph2mol/scgpt_backend/LICENSE).
These components prepare training targets; image inference does not load scGPT.
