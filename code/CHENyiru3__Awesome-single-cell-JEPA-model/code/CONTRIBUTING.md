# Contributing

We welcome paper suggestions, metadata corrections, and resource updates. [Open an issue](https://github.com/CHENyiru3/Awesome-single-cell-JEPA-model/issues/new) to suggest a change or submit a pull request with a README edit.

## Propose a paper

1. Confirm from the paper that the method applies a JEPA or JEPA-inspired latent prediction objective to single-cell or spatial omics. Describe the data, the context the model sees, and the embedding it predicts or matches.
2. Check the README and open pull requests for the title, model aliases, DOI, or preprint identifier. Use an existing row for a revised or published version of the same work.
3. Follow the [README entry format](https://github.com/CHENyiru3/Awesome-single-cell-JEPA-model/blob/HEAD/README.md#contributing). Record the first release date and place the entry in the most relevant section, newest to oldest.
4. Link the paper and any official code or checkpoints. Check these resources separately and note access restrictions in the corresponding column.

## Update an entry

Use the publisher, proceedings, preprint record, or official project release to verify changes. Keep the first release date when updating a paper to a newer version or venue. If the recorded date was wrong, explain the correction and cite the source.

## Submit the pull request

Summarize what changed and include the primary sources behind each change. If you used AI assistance, disclose it and verify the description and links against the original sources. The repository owner reviews proposed changes before merging.
